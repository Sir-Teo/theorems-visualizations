3. NTK: actual parameter gradients and Gram matrices, analytic initialization limit, signed entries, independent color scales and a rank-deficient width-one example. The tangent kernel is distinct from GP covariance.
4. Lazy training: actual RK4 gradient flow versus exact frozen empirical-kernel flow, maximum neuron movement versus total displacement, and relative Frobenius drift. The proof is finite time with bounded fixed data, smooth sine activation and the declared scaling.
5. Kernel regression: exact continuous-time finite-matrix flow, initialization retained off-data, eigenmode residuals and conflicting duplicate labels. No interchange of infinite-width and infinite-time limits; no claim that the finite initial function is already a GP sample.
6. Random Fourier pairs: actual nested frequencies, exact fixed-pair variance, realized grid RMSE/maximum and square root of expected grid MSE. No fabricated monotonicity or expected-maximum/confidence-envelope claim.
7. Spectral bias: exact positive periodic population kernel with reversible eigenvalue ordering. Fourier preference is conditional on the spectrum; no finite network is represented as having been trained.
8. Lazy versus feature learning: centered alpha-scaled output and loss divided by alpha squared, fixed width, actual feature motion and frozen-flow comparison. Feature movement is not equated with better prediction.
9. Mean field: bounded smooth sine features, actual width-accelerated particle flow, explicit weak measure equation and finite-horizon Wasserstein coupling proof. A 512-particle run is a numerical comparison, not an exact smooth density or a global optimum. The bias-free model's odd-function restriction is visible and disclosed.
