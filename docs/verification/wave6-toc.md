## Model and proof contracts

- A PDA transition replaces the leftmost stack top. Acceptance requires all input; final-state and empty-stack modes are explicit. BFS returns a real witness, a complete finite reachable-graph rejection, or an inconclusive budget result. A repeated configuration can be merged in a complete finite graph; a single capped deterministic execution is not a general rejection proof.
- Grammar→PDA uses actual rules; PDA→grammar first changes acceptance convention when necessary, then constructs every triple-variable rule and intermediate-state sequence. Exact finite word sets use a least fixed point; membership uses actual CNF/CYK. Their construction budgets remain visible.
- Pumping uses actual repeated nodes in a recognized CNF parse tree. The non-CFL scenes enumerate every legal split for a selected finite witness; the prose supplies the quantifier argument. Ogden’s example passes ordinary pumping with bound1 but fails marked pumping. Palindrome separation uses the full four-alternating-block case analysis, including symmetry-preserving pumps that break prefix minimality.
- Determinism is checked on every state/top table entry. Epsilon summaries distinguish finite pop, finite stop, and divergence, with a separate final-visit fixed point. Complementation normalizes first and tracks all final visits since the last consuming transition; a raw final flip is intentionally compared and can overlap the original language.
- Parikh automaton states are actual variable-count vectors of total at most nm+1. Actual production edges emit terminal projections. Complete bounded grammar and regular word sets are compared by their count vectors; word order need not agree. A finite lattice window is not a semilinearity decision procedure.
- The bracket representation encodes actual CNF trees. Its finite-memory filter, typed Dyck matching and erasing homomorphism are computed separately. Both child-variable constraints are enforced, and epsilon is handled separately. Manual bracket input has explicit syntax/size errors.
