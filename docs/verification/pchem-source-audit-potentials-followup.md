## Corrections

**3.10:** states the single-reservoir/external-pressure/no-extra-work hypotheses and differentiates allowed equilibrium minima from metastability. The previous constant-volume family subtracted ΔnRT from energy while leaving entropy temperature-independent; its heat-capacity difference and entropy derivative were inconsistent. The corrected family uses ΔC_V=−ΔnR and integrates it to ΔS(T)=ΔS_ref−ΔnRln(T/298.15K). The constant-pressure family has ΔC_p=0. Reference entropy for each family is an independent chosen input; this is not a claim to compute the same measured reaction at both constraints. The default is now explicitly hypothetical rather than an unverified quantitative ice model. Thresholds are solved for the selected family, splitting at its analytic stationary point so two crossings are not missed; an everywhere-neutral curve has no falsely isolated threshold. Plot bars and readouts use the actual system entropy at the selected temperature.

**3.11:** one work convention throughout: q absorbed, w_e delivered, ΔH=q−w_e and w_e≤−ΔG. The original idea switched to input work while retaining the same symbol. Uses the actual JANAF Gibbs value. The current handle now reaches j=0, exposing the reversible *per-reaction* work limit; electrical power at zero current is zero. All permitted resistance/current settings keep the illustrative voltage positive (minimum about0.078V); no negative-voltage defect was found or asserted. The polarization curve remains a model, not a measured device curve, and the heat/work efficiency ratio is tied to the stated liquid-water reaction and standard states.

**3.12:** fixes fixed composition/amount, smooth single-phase potentials and nonsingular natural-variable maps in the hypotheses. Model entropy uses the same gas constant as model pressure. A relative cancellation guard10⁻⁶ reports a singular/ill-conditioned natural-variable Jacobian instead of drawing divergent bars. Finite unstable analytic branches are explicitly identified separately from positive-pressure, mechanically stable branches; even local stability does not prove global equilibrium. The visual comparison retains finite-difference Jacobians; independent tests use separately derived isentropic and isobaric paths. The caption now identifies the actual potential control; the displayed square is a highlight, not a hidden clickable control.

**3.15:** preserves the correct unit conversion100J per Lbar and the homogeneous vdW energy-conservation result. States fixed composition, smooth phase description, positive constant molar C_V and consistent units. The control extremes retain positive absolute temperature (the most extreme CO₂ example is≈27.86K), but may pass negative-pressure or mechanically unstable branches. That continuation is now marked on the actual diagram and readout rather than presented as a stable-gas prediction. A sampled necessary local check is disclosed; no Maxwell coexistence, metastability proof or molecular low-temperature validity is inferred. Chamber widths and particle motion are explicitly schematic and not scaled to the selected expansion factor or a true transient solution.
