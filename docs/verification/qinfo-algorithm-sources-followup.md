## Corrected behavior and assumptions

**3.8:** The source's conditional resource guarantee is separated from the bootstrap toy. Visibility and fidelity are distinguished. The demo explicitly purifies level zero as well as higher levels, reports accepted-pair rate separately from Werner entanglement, and identifies separable outputs. Its finite last-level rate ratio is not labelled proof of a power law. The0.2dB/km value is an illustrative model parameter, not an unsupported universal or measured fibre specification. Log10 rates avoid numerical underflow and spurious floors. Actual rate extents include costly elementary purification at K=0. The simple factor3/2 is restricted to rare-success geometric/exponential waits: for geometric(p), `E max(T1,T2)=(3−2p)/(p(2−p))`, versus `E T=1/p`.

The Werner separability label has a constructive check for0≤w≤1/3. Atw=1/3, averaging the six product projectors `|psi><psi| ⊗ |psi*><psi*|`, for psi along±x,±y,±z, gives `rho=I/6+|Phi+><Phi+|/3`. Smaller w mixes this withI/4. Forw>1/3, fidelity withPhi+ exceeds1/2, which no product state or separable mixture can do by Cauchy–Schwarz. This supplies both directions for the states used here without inferring separability from a failed Bell test.

**4.5:** Retained theorem has inverse closure, fixed gate set, source cost model and fixed-size compilation assumptions. The projective demo uses a scoped commutator that handles exact identity and antipodal alignment with a perpendicular rotation axis. Actual output words are evaluated; error zeros are reported and omitted from logarithmic plots, without flooring. Fitted single-target c is explicitly empirical and does not certify the net's cover radius or theorem hypotheses. Plot extents contain all errors, lengths and the fitted curve. Identity/T/random-target controls exercise finite edge cases. The source theorem is not inferred from sampled convergence.

**4.6:** T insertion invalidates the Clifford-only update route but does not prove the state is non-stabilizer or its measurement probabilities nonflat; T|0>=|0> and T|+> already refute the old text. The display disables the tableau comparison in that case and retains direct matrix probabilities. Both memory curves use bits: ideal packed-tableau logical bits versus Float64 vector bits, with JavaScript object/scratch overhead explicitly excluded. The33-qubit vector reference is128GiB. Small-n and large-n extents are included and overcrowded64-state labels are thinned.

**4.7:** Scoped complex-state evolution is checked against an independently assembled controlled4×4 matrix. The selected state's actual control marker is distinguished from the beta=0 reference curve. Both eigenstate endpoints, equal eigenphases and zero coherence are handled; no fictitious azimuth marker is drawn at zero coherence. Product classification near unit length is explicitly within numerical tolerance, not a certificate excluding arbitrarily small entanglement.

**4.8:** Uniform-register amplitude corrected from1/2 to1/sqrt8; probability bars are distinguished from their phase colours, and raw norm squared is reported before any visualization state wrapper can normalize it. Every truth table is a reversible involution, and the minterm circuit is checked on every basis state. Coherent evaluation does not mean all values can be read from one query. A basis target only becomes entangled when the input has support on both function values; constant functions and basis inputs are not falsely called entangled.

**4.9:** Hermitian finite-dimensional assumptions, operator norm, hbar=1, integer positive step count and efficiently implementable bounded-norm constant-locality terms are explicit. The symmetric bound includes the actual1/12 and1/24 nested-commutator constants. Displayed errors and the first-order bound are unmodified; no invented error floor or clipped bound enters the comparison. g=0 and t=0 are supported; exact zero errors are omitted from log axes. Slopes are finite endpoint observations, not guaranteed asymptotic exponents. Fixed-step dynamics are labelled at integer multiples of tau. For this A-eigenstate input, S2^k=A^(−1/2)S1^k A^(1/2); since Z commutes with A, the two observable curves coincide at endpoints despite different state errors. This is explicitly explained and independently checked.
