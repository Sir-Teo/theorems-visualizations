## Proof and model contracts

- A private verifier tape is hidden from a prover policy. Every allowed finite policy is checked against all eight tapes; leaking the tape deliberately changes the information model. Graph challenges enumerate all permutations with multiplicities, so automorphisms and weighted orbit sizes are genuine. Perfect completeness uses an exact uniform-permutation primitive; a bounded fair-bit implementation has separately charged negligible sampling failure.
- The AM/MA scene computes average-of-row-maxima versus maximum-of-column-averages from an editable verifier table. It illustrates the quantifier order and does not assert a separation between language classes.
- 6.4 proves polynomial-round public/private-coin equivalence through the public-coin PSPACE protocol in6.9. It explicitly does **not** supply the sharper historical additive-two-message simulation. The forward dependency is acyclic. A complete pairwise-hash set-size lemma separately supports the direct two-message GNI argument.
- 6.5 counts canonical pairs (labeled graph, automorphism), not certificate multiplicities. Its MAM collapse uses amplification then a union bound over the first witness. Perfect-complete AM uses strict complement coverage, with density bounds1−1/(2m) and1/(2m), before the quantified hierarchy argument.
- Actual Boolean parsing supports at most four variables,160 characters and63 nodes. Sparse finite-field polynomials have explicit12,000-term/500,000-product budgets; exceeding one gives an input error, not a mathematical verdict. Arithmetization, restriction, degree reduction, interpolation and QBF operations use exact integer field arithmetic for supported primes.
- Sum-check and QBF commit actual polynomials before revealing the next challenge. Degree and consistency checks precede that revelation. Adaptive false claims, manual excessive degree, exact roots, integer-count aliasing and constant formulas are computed. Selected challenges are deterministic replay lists reduced modulo the field, not independent random samples; the stated soundness bounds apply to ideal fresh uniform challenges.
- The coNP proof verifies a prover-supplied prime using the already written Pratt certificate construction. Bertrand's prime-interval theorem is an explicit separate existence input. QBF includes the one-copy polynomial-size reachability construction, all backward operator identities and a polynomial-space upper bound that optimizes only over visible transcripts.
- The MIP scene exhaustively optimizes a small separated clause game and contrasts communication. It is not a numerical proof of MIP=NEXP. The prose distinguishes the full elementary upper bound from the deep BFL robust-test input and states that input's hypotheses and proof boundary. Provers are classical, cannot communicate during the protocol and may coordinate beforehand.
- The permanent checker queries actual minors and an interpolated matrix curve, then descends one dimension. A globally correct program always passes. A wrong initial answer is detected with the quantified high probability; if only other outputs are wrong, either verdict is allowed. The scene checks a finite-field permanent; exact integer lifting is a separate task.
