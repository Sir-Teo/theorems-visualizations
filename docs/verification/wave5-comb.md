## Mathematical and computational scope

First-return convolution, reflected bad paths and binomial formulas are separate independently computed quantities. Empty words, zero-sized trees/matchings, strict versus weak positivity, ballot ties/minority totals and forbidden flaw classes are explicit states.

The cycle lemma is restricted to ±1 words of total1. The unique good indexed cut follows the last global minimum, and total1 prevents a nontrivial rotational period. The ballot proof instead uses first-hit reflection; no special-total proof is stretched to arbitrary lead.

Full ordered binary trees have n internal vertices/n+1 leaves; plane trees have n edges/n+1 vertices. The two actual inverse word encodings differ. Polygon labels/root edge are fixed, with no rotation quotient. Set partitions are independently generated and tested for actual crossing quadruples. The stack widget uses the deterministic “pop next required output, otherwise push” rule and records failure when blocked; no unsorted output is mislabeled as success.

Chung–Feller’s histogram index k is half the2k below-axis edges. The supplied proof decomposes returns into positive/negative primitive excursions, uses B=(1−xC(x)−xyC(xy))⁻¹, and derives B=(C(x)−yC(xy))/(1−y). This gives C_n in every class rather than taking a small finite histogram as a proof. Motzkin paths invert actual partial noncrossing matchings; unused points are singletons.

Parking success and the sorted criterion are proved using adjacent-arrival exchanges and sorted greedy placement, followed by Pollak’s separate circular counting argument. Street and circular alphabets differ; only the unique circular offset leaving the extra spot empty represents a linear parking function. Space labels and car IDs are distinct.

All finite count displays use complete bounded enumerations and exact integer calculations, never samples or prescribed count bars. A built-in gallery control selects floor(p(N−1)); the current rank and total remain visible. The stack-step button changes the saved native slider, with no opaque history. Only the normalized asymptotic product is floating point; its actual finite gap is not an error certificate. The product avoids huge factorials and cancellation of large logarithms, and the theorem follows from written COMB1.19 and the exact Catalan formula.
