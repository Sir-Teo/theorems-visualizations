## Corrections

**4.4: covering alone is insufficient.** The old proof assumed a fresh process remained after using n−1 coverers plus the solo contender, and skipped the induction's hiddenness requirement. The original argument instead uses Lemma 5.3 to put the hidden solo contender in the remainder in an indistinguishable execution, then runs the *existing other processes* fairly until another enters. The new explanation includes the repeated quiescent configurations, outside-target side branches and finite-target recurrence needed to preserve all hidden coverers in Lemma 5.5. The upper n-bit algorithm has static priority, so its lack of Dijkstra's stronger symmetry is explicit.

The old game labelled choosing a covered *first* write a contradiction even when m≥n. A first covered write says nothing about later writes before entry. The replacement is an executable memory/erasure illustration with explicit premises, not a purported exploration of every mutual-exclusion algorithm. Up to n−1 distinct pending coverers can be selected. A hypothetical trace writes 1 to the chosen cover and optionally outside it; fixed coverer writes of 0 erase precisely the covered cells. A surviving outside write is visible. With test-and-set, equal final memories can still leave different returned old bits in the coverers' local states, invalidating indistinguishability. The readout no longer applies the read/write lower bound to that stronger primitive. Every finite cover subset through six registers is independently checked.

**4.6: cyclic interleaving, not simultaneous accesses.** Stated anonymity, symmetric initialization, local passive cells, one-cell operations and global progress. The source Theorem 1 sketches a cyclic order of individual atomic actions; the old “simultaneous” engine precomputed competing intentions then resolved them in index order, potentially introducing scheduler asymmetry inside a supposedly symmetric step. The engine now executes actual single-seat actions against current state. The chosen deterministic hold/polite programs retain exact symmetric deadlock/livelock cycles under cyclic order. The second scheduler is explicitly eight consecutive actions per seat per round, and is distinguished from the one-action cyclic schedule. A left-handed seat changes the program, as stated. Program counters agreeing alone are not described as a fully rotationally symmetric fork state.

**4.7: the free algorithm permits starvation.** The original's Theorems 3–4 directly contradict the old assertion that this basic program is lockout-free. Probability-one global progress belongs to the free program; individual probability-one progress belongs to the separate courteous program with extra neighbor signals and last-eater memory. Removed the unsupported uniform 1/8 success claim within bounded scheduler time. Proper schedules are non-anticipating, may see all past outcomes, and activate each philosopher infinitely often for every coin sequence. Arbitrarily long finite delays remain allowed.

The actual simulation now separates random draws, first-fork acquisition, second-fork attempt, failed release, eating and each of the two post-meal releases. No step changes two fork cells. Owner IDs are external bookkeeping for drawing, not identifiers available to the anonymous program. The two displayed schedules are genuine interleavings. Exactly the requested number of actions is run, without rounding up to a whole simultaneous round; the step slider reaches exactly 50 and 5,000. “Never ate” became “no meal within the budget,” with the median explicitly conditional on observed first meals. Three hundred chosen deterministic seeds illustrate behavior, not a probability-one proof or a guarantee for every individual.

**4.13: source-checked Dijkstra transcription.** Replaced the memory-based historical description with exact original requirements, program and argument, removing uninspected historical embellishments. The old combined `if b[k] then k←i` was one read-modify-write action; it even combined the shared index read with the Boolean read. It now has a private index read, a separate Boolean read and a later write, admitting the delayed assignments discussed in the original proof. Both naive comparators also scan flags one shared read per action. All code rows fit the expanded program panel.

Private index/counter temporaries are cleared after their last use; this preserves the visible execution and future behavior without retaining irrelevant stale values in state keys. The complete finite graphs have **264 states for N=2** and **8,084 for N=3**, for each valid initial k. The UI explicitly distinguishes its finite safety/fixed-state-deadlock test from infinite-run progress and reports caps as incomplete. Separate independent SCC tests below actually exclude a fair no-critical tail for these two finite models. Neither finite graph proves the general theorem or starvation freedom.

Random-run buttons previously repeated the same seed after the second click; seed state now advances monotonically and the actual seed is reported. A final fixed-state deadlock is tested by all possible next actions rather than inferred from a long repeated random sample. Observed waits are in all scheduled actions and can be censored by the run endpoint.
