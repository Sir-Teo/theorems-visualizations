## Repairs and exact model

The old parser treated E/e as numeric11 before attempting note names, so the advertised note-name input containing E could not correctly enter the source Berg row. Numeric and note-name grammars are now explicit. Numeric0–11/T/E does not reduce out-of-range integers modulo12; note-name E means4, with up to two accidentals. All twelve pitch classes must be distinct, so enharmonic duplicates are rejected.

There is no hidden last-valid row or unregistered selected form. The model derives from the registered input text, syntax, family and matrix index. Invalid text renders an error and disables playback; it can be saved and restored as that same error. Preset and seeded-row buttons write the actual saved input. Selecting family and index, clicking a matrix cell, or clicking any edge label updates the same registered controls. A cell selects a row for P/R and a column for I/RI. The matrix highlight, readout and actual audio share the selected ordered sequence.

For row p, Mij=pj−pi+p0 modulo12. Rows are translated p and columns translated inversions; thus all are permutations. Retrograde reverses the ordering. Labels use the first pitch of the associated forward P/I partner, explicitly including when its retrograde is selected. All48 operations are enumerated as ordered sequences; exact stabilizers also enumerate direct affine/reversal actions. Distinct count times stabilizer count is48. The chromatic row has24 forms, the Berg row48. The all-interval check uses all eleven nonzero directed successive intervals, not just six unordered interval classes.

Synthetic playback is fixed-register C4–B4, H8 with1/h amplitudes,44,100Hz mono,0.3s per note,0.02s gaps,10ms ramps, raw bound0.12, voice gain1/master0.9/limiter. Every event is sub-Nyquist and its pitch order matches the selected form. No performance register, rhythm, timbre or score orchestration is reconstructed.
