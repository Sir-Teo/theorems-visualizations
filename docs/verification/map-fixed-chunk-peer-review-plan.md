## Review order and first-failure rule

Execute the native ladder sequentially. The first failed source, arithmetic, ownership, image or lifecycle gate stops further native cases; preserve the failing state, raw readback/difference and own screenshot, then report it. Do not continue to other widths/themes or run FPS to compensate. A repaired candidate requires a new immutable hash and bounded rerun beginning at the failed boundary. Successful read-only models are not an implementation oracle.

1. **Boundary and provenance.** Archive the exact candidate and original reference. Inspect the full diff and hash every routed asset/helper/input; prove production, original shader/union/fallback and shared runtime boundaries are preserved. Confirm the test's reference switch invokes the actual untouched original group binding, not another reconstruction of the candidate. Record all node/ordered-endpoint identities, definition/planned/field controls, frozen graph/data/CSS hashes, browser/DPR/theme and source commit. Frozen checkpoint5/source68aa4e2 is allowed for initial correctness diagnostics. Any eventual separately authorized performance work must use the current accepted checkpoint6 input and its verified identity, with no competing FPS work.
2. **Source, stream and allocation proof.** Read exact enumeration, bound-domain checks, metadata creation/release, chunk packing/upload, partial-tail count, state restoration, owner transitions and every fallback branch. Verify original IDs/path/ranges/saved Float64 coverage and their order/multiplicity against actual original construction. Preserve first-point integers, endpoint cull, shaders, uniforms, scissor partition, cap/dash and outer style order. Unsupported/nonfinite/uncertain bounds must include or use original binding; no ad hoc new endpoint reject. Test missing metadata and absent optional capacity before any alternate binding. A model/fidelity number alone is insufficient ownership identity.
3. **Tiny actual binding/image rung.** Start with a small nonempty same-scene original-versus-alternate GL readback, with complete state reset and no animation. Require identical RGBA for the same original mesh/state; this is an extra direct equivalence diagnostic, not a relaxation of existing Canvas image gates. Exercise real chunk boundaries using small test capacities on tiny fixtures, then configured32768 on a genuine multi-chunk case. Independently observe actual buffer/count calls, not only candidate-reported success. Check both caps/dashes, duplicate and crossing opacity, distinct overlapping style colors, fractional phases, tile boundaries and a final short prefix after reuse by a different style/tile. Empty prefixes draw nothing; only complete successful scans can prove transparent skipped tiles.
4. **Actual partial-failure rung.** Force the real catch/fallback branches after a submitted prefix, around upload/pack and immediately before composite. If the complete original frame/group/model/view/control snapshot is still live, restore state, clear that same mask rectangle, replay the original full group and composite once. If any owner/frame snapshot expired or was released/replaced, require complete original frame restart from its normal clear, or complete Canvas fallback; never old-buffer replay or mixing a new frame with previously composited tiles. Context/framebuffer unusability requires complete fallback. No full-color overlay may replay already composited tiles. Compare resulting actual image/state with the corresponding complete original reference.
5. **Full-map and lifecycle rung.** Only after the earlier rungs pass, cover normal, actual320px and oversized map sizes, both themes and DPR1/2, including selected/hover/selected-hover/highlight/filters. Exercise covered camera group reuse and coverage misses, fractional pan/zoom, width/cap/style invalidation, original far bundled/direct bypass, fidelity transitions and missing optional metadata. Inspect own complete output pixels and any boundary/crossing crops. Check actual hit/selection/input state, no stale layers or histories, and unchanged node/label rendering. Force font/theme/control changes, late/cancelled metadata responses, original group/model growth, context loss/restore, unavailable GL, reservation/allocation failures and destroy/recreate. Original frame/state and cleanup must remain correct.

## Resource evidence required at every allocation stage

Retain the existing **64000000 logical byte cap**, **8000000 mask-pixel cap**, original no-MSAA/input-canvas behavior, resource component reconciliation and complete destroy cleanup. Existing Canvas-reference gates remain **mean difference <2** and **fraction of RGB channel differences >20 below0.02**; do not widen them or hide a new same-scene discrepancy inside those looser Canvas approximation gates.

The stronger combined logical total must count all newly retained CPU metadata/scratch and GPU scratch alongside every original GPU/native owner. One32768-index pair is **131072 CPU +131072 GPU =262144 bytes**, not32KB total. Original full group buffers remain available. No original CPU membership copy, retained complete upload arrays, all-model metadata, all-tile/history caches, hidden slice/spread payload copies, geometric capacity growth or unreserved old/new coexistence may be omitted. A subarray view does not copy its payload, but its lifetime and upload overload remain inspectable. Distinguish live retained logical ownership from existing CPU construction, GC/deferred release, native upload staging and physical driver/compositor storage; no physical/process ceiling follows.

Require independent observations before reserve/allocation, after creation, during replacement/failure and after release. Source inspection must corroborate declared owner sizes and buffer capacity; merely reporting `budget.bytes` is insufficient if CPU arrays were never charged. The actual allocator can evict original eligible owners even when a new scratch owner is non-evictable. Use a synchronous no-eviction preflight for **all** optional owners, and release optional x/y/pair before later original model/mask/group/font-owner growth can encounter pressure. Required original behavior/prewarmed resources must match the original baseline, rather than disappearing to make the optimization fit. Releasing an optional logical owner is not proof of immediate physical driver/GC deallocation.

All new descriptor/metadata/worker references need generation and owner cancellation. A readable stale array is not a live GPU owner. Destroy/context restoration must leave no pending work, optional arrays, hidden canvases or old buffers; no late result may resurrect them. Existing complete fallback remains usable if metadata is unavailable or any optional allocation fails.
