## Minimal discriminating observations for a separately authorized diagnostic

First preserve both original raw buffers, metadata, errors, ordinals, thresholds, and comparison result. Any added captures must have new names and output paths and must not replace the failed oracle. Record state and bytes **before** assertions and teardown. A later successful paint cannot stand in for an earlier failed capture.

| Hypothesis, not finding | Minimal observation | Distinguishing outcome |
| --- | --- | --- |
| Different paint order or intervening mutation | An ordered log around scale-8 `_draw`, acknowledgement, destroy/fallback, explicit actual paint, each pending catch, reference paint, and final read. At each boundary record Canvas identity, width/height assignments, paint ordinal, map `W/H/dpr/k/tx/ty`, hover/selection/highlight/filter IDs, raster-cache identities, generation/dead/status, opacity/display, pending RAF IDs, and raw-buffer hash. | Different actual-paint and final-read hashes localize an intervening mutation. Equal hashes reject that explanation for that interval. Do not infer pixel changes merely from a status change. |
| Connection or inherited text settings affect glyph rasterization | At the original actual and detached-reference paints record `isConnected`, parent identity, element language/direction, bounding/client dimensions, and computed font family/features/variations/kerning/smoothing/text rendering/letter spacing. Record actual label `measureText` metrics and draw positions. Preserve the original detached pair; only a separately authorized additional control may compare a matched connected fresh Canvas. | Equal geometry but differences confined to glyph coverage support a text-raster hypothesis. A connected control agreeing with actual would be evidence for that control's conditions, not automatic authority to replace the original reference. |
| Existing context history differs from a fresh context | Before and after each original paint record `getContextAttributes()` when supported, transform, global alpha/composite, filter, line width/cap/join/miter/dash/offset, shadow settings, smoothing settings, font/kerning/stretch/variant caps/text rendering/letter spacing/word spacing/alignment/baseline/direction/lang where supported. Record unsupported properties explicitly. Trace real save/restore and clipping operations if needed; the current clip cannot be inferred from `getTransform()`. | A concrete differing property plus affected primitive identifies a candidate mechanism. Equal observable properties alone do not prove equal hidden clip or text raster state. Do not reset the old actual context to manufacture agreement. |
| Font availability or metrics changed between paints | At both paints record `document.fonts.status`, exact `document.fonts.check()` results for the fonts actually used, loading/loadingdone/loadingerror event order, and complete label metric tuples. | A change in readiness or metrics supports font timing. Initial `fonts.ready` alone cannot exclude it. Matching metrics do not exclude glyph-coverage differences. |
| Reference paint reads different live map or palette state | Record the same ordered map inputs and resolved colors immediately before both calls, plus the actual primitive sequence and arguments if the small state snapshot does not explain differences. The reference swaps only `m.ctx`, so record both `m.ctx.canvas` and `m.canvas` identities. | Different arguments identify state divergence. Identical arguments with different pixels move attention to context/rasterization, without proving the latter's cause. |
| Export or comparison changes the pair | Preserve original RGBA lengths/hashes/orientation, identify exact compared labels and ordinals, and report raw RGBA difference bounds/channel counts alongside the unchanged composited RGB comparison. Record resolved background versus the declared compositing background. | Raw-equal but RGB-different images identify a conversion issue; raw-different images establish that the discrepancy predates comparison. Keep full-image counts; any glyph/shape localization is supplementary, never an exclusion mask. |

Begin with metadata and original-image provenance, then choose only the smallest additional observable needed by the remaining ambiguity. A new connected reference, property normalization, extra redraw, wait, or altered order would be an experimental control requiring separate root scope. None is proposed as an accepted-script change or an unchanged retry. Stop on the first unexpected repaired result and retain all raw evidence. Actual context loss/restoration, full-map readiness, lifecycle acceptance, performance, and production acceptance remain outside this plan.
