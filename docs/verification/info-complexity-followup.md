## Primary evidence and theorem scope

Peter D. Grünwald and Paul M. B. Vitányi, [*Algorithmic Information Theory*, author chapter](https://homepages.cwi.nl/~pdg/ftp/HPI.pdf), dated **July 27, 2007**, 37 pages. Retrieved 2026-10-18, SHA-256 `fc24f735bf57a568126bbe018dbe4d208aabebc9f23553367fd6fde9bf4209d5`. Definition 6 is on printed/PDF **p. 16** and explicitly fixes a universal **conditional prefix** machine. Theorem 10, printed/PDF **p. 21**, bounds expected unconditional prefix complexity above entropy with overhead `K(P)+O(1)` for computable distributions. Both original pages were rendered and inspected; §1, p. 2, supports the retained historical background.

The previous generic “universal computer” wording did not imply the prefix condition needed for the lower entropy bound. The replacement states this condition, a fixed known finite alphabet, known length, i.i.d. sampling, and an expectation conclusion. It gives an elementary conditional version using a type-class code; it is **not presented as the verbatim statement or numbering of Theorem 10**. Removed the unsupported Cover–Thomas theorem-number attribution.

For every length `n≥1`, encode all `m` counts using `m ceil(log₂(n+1))` bits, then a rank using `ceil(log₂ M_T)` bits. The count field determines the rank-field length, so this is prefix-free conditional on `n`. Each positive-probability type is uniform under any i.i.d. law, including noncomputable parameter laws. Thus `E log₂ M_T = H(Xⁿ|T) ≤ nH(P)`, yielding the rigorous upper overhead `m ceil(log₂(n+1))+1+c`. The decoder depends on the fixed alphabet and reference machine, not `n` or `P`. This replaces an insufficient unrounded `m log₂ n` field count and a proof that appealed only to typical strings. No per-string closeness to entropy follows.

## Implementation and figure corrections

- **KT:** The old helper computes fractional predictive log loss, not an emitted arithmetic code. The plot now draws the constructive Shannon–Fano–Elias prefix-length bound `ceil(-log₂ Q(x))+1`; its fractional ideal loss is separately identified in the readout. Large-input codewords are not claimed to be generated. The dedicated helper computes the ceiling using exact integer KT probabilities `Q=A(n,k)/4ⁿ`, with `A(n,0)=binom(2n,n)` and the exact count recurrence. Floating log accumulation cannot incorrectly round a length down at an integer boundary. The midpoint construction and its prefix property are independently checked for all binary strings of lengths 1–10.
- **LZ:** Added a custom emitted binary LZ78 pair code and an actual decoder, both conditioned on known source length. Pair `j` contains `ceil(log₂ j)` pointer bits and one symbol bit. A repeated terminal phrase is emitted as its parent/symbol pair; decoding stops at exactly `n` symbols. The length curves encode each displayed prefix rather than adding one phrase unconditionally, fixing exact-boundary and final-endpoint overcounts. This is explicit custom framing, not a claim to reproduce an original paper's bitstream.
- **Complexity:** Neither fractional loss nor a compressor length alone is an upper bound on the selected machine's `K`; the relevant decoder constant must be added. Removed the arbitrary `260/n` curve and its off-viewport annotation. The unknown constant is not assigned a numerical value.
- **Simulation:** Both browser modes are now explicitly seeded algorithms. The resample control changes both modes' actual output. Fixed bias/algorithm/seed prefixes have a constant conditional generator description, with unknown size; the finite plots are not measurements of true `K` or observations from ideal infinite i.i.d. randomness. Replaced claimed convergence/crossing guarantees for individual finite curves with the correct expectation distinction.
- **Controls/ranges:** The followed bias has a genuine selected point on each right-panel curve at the selected length. Readouts report those points rather than always reporting length 20000. Each panel's vertical range includes every plotted value, including short-string overheads. Existing dependency arrays are unchanged.
