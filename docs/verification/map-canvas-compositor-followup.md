## Bounded implementation

`scripts/lib/map-canvas-compositor-prototype.mjs` rewrites a frozen copy of the production graph module only inside the explicit fixture. It retains the complete original `_paint()` and `_draw()` bodies byte-for-byte (the latter renamed `_drawOriginal`). A model test independently checks that preservation.

For moving, unselected, unhovered, unhighlighted views whose full-resolution stores fit, the prototype presents three connected Canvas layers in the original painter order: backgrounds plus region/chapter/collection words; cached edges and nodes; then current native node words on the original stable input Canvas. Native text is repainted at the current camera and physical resolution, with the original font and label/collision code. Geometry reuses the existing Canvas paths, grouping/opacity union and native node painter. It changes a CSS transform instead of issuing a full-frame Canvas `drawImage` on each eligible cache hit. Actual drawImage interception in the native suite verifies the zero-copy Canvas API claim; this does not claim that Chrome's compositor or driver performs zero internal copies.

Reuse requires coverage, matching dimensions/filter/theme/LOD identity and a 0.9–1.1 source-scale ratio. Tests cover 0.901 and 1.099, fractional pan, coverage failure, .13 and 1.15 LOD boundaries, and larger-scale rebuilding. This narrower envelope may increase expensive rebuilds relative to production's wider moving raster range. Performance improvement is a hypothesis, not an established result. CSS geometry resampling changes antialias/stroke coverage within the stated image bounds; pixel identity is not claimed for moving composed pictures.

All ineligible frames release compositor stores and delegate to the **unchanged original cached draw path**. This preserves the already-fast selected/hover paths rather than replacing them with unconditional full repaint. The oversized resource fallback remains production's direct full-resolution Canvas painter. The stable original input Canvas keeps its native handlers, focus and hit coordinates; extra layers have pointer-events none and aria-hidden. Font/theme invalidation, resize, unsupported allocation, paint exception and destruction release/invalidate the appropriate stores. A forced painter exception is tested for original fallback and subsequent recovery.
