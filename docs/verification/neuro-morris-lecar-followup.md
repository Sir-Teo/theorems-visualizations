## Corrections

The SNIC theorem now requires the attracting invariant circle, a single generic bottleneck and bounded return time outside its neighborhood. It no longer claims that a local fold automatically creates a stable cycle or that all initial conditions below threshold are at rest. The critical connection uses the center direction, not a returning strong unstable manifold. The normal form keeps both coefficients: xdot=aδ+b*x², a,b>0, so T~π/sqrt(abδ). Its finite-cutoff integral is stated before the asymptotic limit. A finite ML trajectory does not certify the global invariant-circle connection or an exact asymptotic exponent.

The old fold locator bisected the number of roots found on a.1mV grid, losing close pairs. A new scoped helper solves the stationary points of the equilibrium-current function analytically differentiated in V and partitions the monotonic branches to locate all roots, including the double root. The positive fold is I=39.96315309274536,V=−29.389777405484395 with transverse eigenvalue−.09904878852914784/ms; determinant is numerically near2.2e−18. At I_fold−1e−8 the close node/saddle are both retained; at the fold they are one nonhyperbolic equilibrium; above it they vanish. No nullcline-denominator pole is mistaken for an equilibrium.

The rate helpers now report actual interpolated upward crossings after the first third of the chosen run and return unavailable with fewer than three retained events. Missing points are omitted rather than drawn at zero, including logarithmic axes. The cache includes the actual parameter object, input grid, total time and numerical step. Each phase, step and rate protocol is described, since their initial conditions and observation windows differ. ML step traces start at the actual zero-input equilibrium and split the input exactly at50ms. Numerical model rates are not measured cell data or a claim about every attractor.

The near-fold regression actually gives slope **.4591482067 over8 resolved points** on.1≤I−Ic≤3; it is reported as a finite-range regression rather than an asserted straight line of slope½. The square-root coefficient is empirical. Plot domains include the entire rate grids, actual orbits/traces/equilibria, positive log data and fitted guides. The source1.05w view corrects the former upper.75/.8 ranges. Nullclines are sampled and clipped by interpolating boundary intersections rather than flattening out-of-view values; this is a rendering approximation. The rate panel has horizontal padding so the selected112 endpoint marker is visible.

All common constants and both distinct gCa,V3,V4,φ choices are listed in the scope with units. φ has units/ms, while the cosh time-shape factor is dimensionless. The old “two parameters V3,V4 andφ” count is corrected. Actual finite comparison replaces the unsupported exact firing-onset/bistable-window claims. Existing shared helpers are unchanged.
