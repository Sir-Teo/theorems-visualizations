## Corrections and mathematical review

**4.9:** The algorithm now requires nonzero elimination pivots and distinguishes exact breakdown avoidance from a blanket numerical-stability promise. Strict row diagonal dominance does not imply all Thomas multipliers have modulus below one: the explicit strictly dominant matrix `[[2,1],[100,101]]` has multiplier 50. Strict dominance is preserved under its scalar Schur step, while symmetric positive definiteness also preserves a positive Schur complement. These give the stated exact-arithmetic hypotheses. The independent scalar count is `5(n−1)+1+3(n−1)=8n−7`; dense counts in the diagram are leading terms. The generalized band cost includes bandwidth-zero cases. Historical priority claims without the original Thomas report were removed.

The table formerly labelled a right-hand-side column but returned `null` for every entry. It now shows each actual updated right-hand side and highlights the changed row. Subdiagonal entries already eliminated are displayed as zero, so the table represents the current augmented system rather than mixing the original lower diagonal with the transformed upper system.

**4.10:** The statement now specifies the positive definite setting for Cholesky, a lower factor `L`, generic symbolic fill rather than inevitable numerical nonzeros, and the exact arrow counts. A Schur update joins remaining neighbours. This proves the star examples by induction and prevents cross-component fill. Minimum degree is the source's dynamic heuristic, not a guaranteed optimum. The unsubstantiated NP-completeness/nested-dissection/priority side claims were removed; a random ordering is no longer declared invariably worst. The existing symbolic and minimum-degree implementations survived independent path-characterization checks, including disconnected graphs, so no shared helper changes were needed.

**4.11:** With a fixed linear correction solver `C`, exact residual and update arithmetic gives the displayed error recurrence `e_next=(I−CA)e`. Actual rounded solves need not be linear maps, and Moler's error terms are identified separately. Small condition number times roundoff is a useful sufficient-condition guide only after factorization/dimension constants; its exceeding one is not a necessary divergence condition. A diagonal binary example with κu far above one is solved exactly in the regression tests. The false guaranteed digit gain, mandatory floor and no-forward-improvement statements were removed.

The experiment now explicitly says both residuals and iterate updates use doubles, unlike the low-precision factors/corrections. Forming `b=A*x_star` in doubles also perturbs the reference comparison. Dashed curves are heuristic scales. Rounded factorization/correction failure is reported, and plot bounds include every finite error and reference-curve point rather than clipping growth. Simulated precision is limited to 8–26 significand bits, reducing double-rounding effects in the underlying JavaScript operations.

**4.12:** Exact block factorization handles a zero trailing column with a zero scalar block; if every remaining diagonal is zero but an off-diagonal entry is nonzero, the corresponding two-by-two principal block has negative determinant and is invertible. Schur-complement induction gives existence; congruence gives exact inertia equality. The source's actual column/row pivot tests replace the oversimplified explanation. The contradictory claim of a dimension-independent exponential growth bound and an absolute bounded inverse were removed. Leading efficient-factorization cost is distinguished from this small teaching implementation.

A dedicated helper normalizes by max absolute matrix entry before applying the verified pivot rule. It replaces the former fixed absolute scalar breakdown threshold with an exact-zero check and restores block units even on early termination. Numerical inertia uses `64*n*EPSILON*max_abs_eigenvalue` separately for A and D. Its middle bucket means unresolved near zero, not certified nullity; disagreement is never dismissed as harmless. The displayed reconstruction error is relative, never rounded to an artificial exact zero. Eigenvalue positions formerly clamped to ±5.9 now use a dynamic axis and their actual values. No existing shared helper was edited.

**3.15, open:** Removed the unverified current-best SPD claim, unsupported historical priority/detail and Hilbert 34ⁿ assertion. The caption separates exact-rational Hilbert reference inverses converted to doubles from rounded algorithm inputs; random references are explicitly double precision. Error and residual norms are distinguished. Both comparison curves and the scatter diagonal are illustrative, samples need not lie on the diagonal, and relative error can exceed one. All finite points fit the expanded axes. Failed selected-family solves are counted explicitly, the final-n readout no longer borrows an earlier successful error, and plotted paths do not bridge failures. The precision control is limited to 12–26 bits. Original historical review remains flagged.
