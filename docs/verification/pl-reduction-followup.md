## Corrections

The shortest displayed join no longer decides exact one-step diamonds: successor intersection is checked separately. Invalid-input buttons no longer call the reducer with an absent term. |
| `pl-3.9` | Replaced a false blanket promise of applicative normal forms with the actual abstraction law `([x]M)N →* M[x:=N]` for λ-free M. Ordered clauses and η’s free-variable condition are explicit; the default translation preserves β-equivalence of λ interpretations, while the shortcut preserves βη-equivalence. Divergent terms remain divergent. Comparison arguments are now fresh against every name in the input, instead of fixed a,b,c,d which could capture intended observations of open input. Actual rules and derivation contexts agree with an independent checker, including repeated binder names, free variables, absent annotations and ill-typed applications. |
| `pl-4.11` | Strong normalization is sourced to the complete reducibility proof. Replaced the untypable duplication example with a valid typed duplication example. Removed remembered growth claims and the assertion that all recursive-type extensions necessarily fail. A cycle can coexist with a normal-form path, so no absence of normal forms is inferred. Every admitted typed sample is validated; rejection count is shown.
