## Model and explicit limits

The inner sphere has a=21.65m and a chosen12° opening. Radial thickness is1.2m through30°, then grows linearly to6.4m at90°; the stepped option rounds this chosen law upward in six increments. Density is uniform at one chosen endpoint or interpolates from top to base over15°…85°. The permitted endpoints include a top-heavier case, so the prose does not assume that every interpolation is lighter aloft. The authored mass reduction acts over25°…75°. These are declared radial-volume laws and parameters, not a surveyed historical reconstruction.

Surface weight is w=ρg[t+t²/a+t³/(3a²)], g=9.81. Let W(φ)=2πa²∫w sinφdφ from the opening, and Q=W/(2πa sin²φ). Vertical equilibrium gives meridional resultant Nφ=−Q; normal equilibrium gives Nθ=Q−aw cosφ. Resultants are kN/m, not concrete stresses. At the equator, Nθ=W/(2πa), so any added step-model weight strictly increases the base hoop resultant; the model and independent tests verify ΔNθ=ΔW/(2πa). Added mass can have a different local effect through the local-weight term. Neither implication is a whole-building safety statement.

Eight-point Gauss integration is split across every smooth interval. Both one-sided values of all weight/thickness jumps are retained. Each plotted smooth segment is sampled at most0.5° apart; plotting never bridges the jumps. Continuous zero crossings are bracketed and bisected within smooth intervals, while sign jumps are separate events. The default stepped case has continuous zeros around67.137587° and70.028623°, with a separate sign jump at70°. It does not mark that jump as a zero. Maxima are over plotted samples, and neither quadrature nor crossing detection is a formal interval or exhaustive root-count certificate.

Each saved continuous control has a bounded finite domain, at most15 significant digits, and an exact native range roundtrip check before calling the shared setter. Actual DOM values equal the registered/model values exactly. Unsupported raw states reject visibly and fully roll back, including numerically unused density controls. There is no camera, random, drag or audio state.
