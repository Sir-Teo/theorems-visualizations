## Corrections and mathematical scope

**Certificate-aware search.** Added a dedicated helper, `ch05-coloring-audit.shared.js`. Every reported upper bound comes with an actual proper coloring. Lower bounds come from an explicit clique (or maximum degree for a line graph) and completed negative searches. An exhausted search budget never increases the lower bound. Previously edge coloring reported χ′≥Δ+1 whenever a Δ-color search failed to produce a coloring, even if it merely timed out. Vertex and Grötzsch demonstrations now retain a valid greedy coloring instead of dereferencing a null search result, and report intervals when optimality is unresolved. The editor's button is now “Show a certified colouring,” with explicit feedback if its seven-color palette is too small. These finite searches do not prove the cited universal theorems.

**Vertex/edge editor semantics.** Reducing a palette removes colors outside that palette; the old display retained hidden extra color classes. Deleted edge keys are pruned. Alt deletion is gated by the edit toggle, matching the caption. Both forward and Shift-backward click cycles, actual graph editing, and empty graphs are checked. The vertex explanation distinguishes nonempty edgeless graphs (χ=1) from the empty graph (χ=0); line graphs with no vertices have χ′=0. Search notices are cleared when manual edits or palette changes make them stale.

**Four colors.** The map equivalence is scoped to a finite polygonal map with connected countries and shared border arcs; point contacts do not require different colors. The proof explanation describes unavoidable and reducible configurations and makes clear that the samples are illustrations. The old histogram classified an unresolved 3-color search as requiring four colors, and an unresolved 4-color search as requiring five. It now separates “3 proved,” “4 proved” and “unresolved.” These triangulations contain triangles, so a found 3-coloring establishes χ=3; a completed 3-color impossibility search plus a found 4-coloring establishes χ=4. No unresolved outcome is labeled a theorem counterexample. The generator is expressly not a uniform sample of all planar graphs. The plot extends to 115% so labels above a 100% bar remain visible. Fallback attempts and red conflicts are labeled heuristic; lack of a conflict-free attempt is not a negative proof.

**Five colors.** The proof handles the small-vertex base case explicitly. A simple path in a Kempe component, together with the two spokes to the removed vertex, forms the separating cycle. The second pair of colors is disjoint from the first, preventing a crossing; the old unsupported explanation of why Kempe's four-color argument fails was removed. A proof-run swap count describes that particular run, not an intrinsic minimum number the graph “needs.” A bounded unsuccessful search for a swap now says so. The dedicated wrapper validates every frame's palette, proper colored subgraph and low-degree deletion, and final completeness; it throws visibly if the legacy helper's emergency sixth-color fallback is ever reached. It was not reached in the audited test family. Independent tests verify actual Kempe components and swaps, including a component containing only one of the two colors.

**Grötzsch.** The statement matches Theorem 5.1.3. The text no longer presents an uninspected inductive proof sketch as if verified. It accurately says the chapter states the theorem and its notes refer to Thomassen's proof. Preset K4 and the wheel on C5 are planar with triangles and require four colors; the Mycielski/Grötzsch graph is triangle-free, nonplanar and requires four; C5 satisfies both hypotheses and needs three. The caption previously said every other preset broke a hypothesis, which incorrectly included C5.

**Greedy and degeneracy.** Corrected “smallest-last achieves col(G) colors” to **at most** col(G). The crown example gives a concrete strict inequality: χ=2, col=5, label-order greedy uses five, smallest-last greedy uses two. The readout separates colors used at the currently selected frame from the eventual run total. Proposition 5.2.2 explicitly concerns a nonempty finite graph and nonempty subgraphs, avoiding undefined minimum degrees for an empty subgraph. Its proof says the last vertex of H has **at least** δ(H) earlier neighbors. The degeneracy slider's maximum follows the actual graph order rather than leaving a misleading 16-step range for a nine-vertex graph.
