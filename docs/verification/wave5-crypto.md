## Mathematical/model scope

- Strong new-pair MAC security versus fresh-message security is explicit. Unique valid deterministic tags justify equivalence; deterministic signing by itself would not.
- PRF→MAC uses one final guess, full transcript conditioning and Q+1 reduction queries. CBC uses fixed/prefix-free domains and a checked zero IV; an actual AES two-block forgery demonstrates the unrestricted-length failure. AES's PRP/PRF loss is distinguished from the theorem's PRF assumption.
- One-time affine authentication exhausts all257 conditional keys, including a=0. Reusing two tags recovers a,b. GMAC and Poly1305 have actual distinct arithmetic and no fabricated common exact2^-128 forgery bound.
- Collision/preimage/second-preimage games differ. SHA truncation traces use distinct deterministic public inputs; they are not presented as uniform simulations proving the ideal birthday formula. Exact birthday probability uses log1p/expm1 and handles q≤1/q>N separately.
- Floyd's constant-memory algorithm is separate from the renderer's stored orbit. A tail of length zero gives no distinct-predecessor witness; the permutation mode correctly supplies none.
- Strengthened MD padding binds exact original length without overflow. The reverse proof compares every compression block covering the whole length field before inferring equal lengths. SHA256 uses original BIT length and UTF8 byte counts. Prefix continuation is an actual resumed SHA256 state; HMAC uses real normalization and both hashes, with a related-pad assumption caveat.
- Davies–Meyer uses actual AES message keys/feed-forward. The separate8-bit affine sponge is deliberately insecure, injectively pad10*1 encoded and explicitly not Keccak/SHA3. Ideal models are not inferred from an arbitrary hidden capacity.
- Lazy oracle sampling has a complete transcript induction; the public seeded table is only a finite illustration. Merkle leaves/nodes/padding/root have distinct byte prefixes, with list length/index/byte length bound. Password counts are exact direct HMAC-work counts; salts add no password entropy, tiny iterations are not recommendations, and Argon2 is not falsely implemented.
- CCA excludes the exact challenge but allows related ciphertexts. The25-byte counter-mode sample exposes every byte. EtM authenticates the full nonce/ciphertext, uses separate keys and rejects before decryption. Its proof separately supplies strong-MAC integrity, CPA secrecy and the integrity-to-CCA hybrid, without claiming every other composition is always insecure.
