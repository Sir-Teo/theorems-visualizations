| Existing claim or limitation | Complete-primary comparison |
| --- | --- |
| Output measured directly | Methods pp.363–365 describe timed collection in a graduated vessel. |
| Reservoir and resistance protocol | Early inflow changes used reservoir height; later experiments used a venous screw clip, pp.364–366. The separate arterial resistance was pneumatic. The caption’s arterial-screw-clamp claim was corrected. |
| Filling and sustained output | Discussion pp.365–368 and conclusions 1/3/4/10 explicitly connect inflow, diastolic filling and per-beat output within working limits. Failure/overdistension can reverse the rise in output. |
| Arterial-load dependence | The paper distinguishes fixed inflow from fixed venous pressure, pp.357–358/368 and conclusions 6/7. The modern model independently controls filling pressure; it is not a reproduction of fixed-inflow trials. |
| Isolation and hormones | The original compares altered external pressure conditions with the intact animal, pp.361–363/375–376. Some experiments used adrenaline (Table IV/V), so the old claim that the preparation removed hormones was false. |
| Visualization scope | The chapter’s left-heart, fixed-rate model is still explicitly illustrative. It does not reproduce two-sided failure, changing rate, fatigue or the original dog measurements. |
