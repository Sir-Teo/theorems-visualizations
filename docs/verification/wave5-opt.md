- Weak duality is unconditional; strong duality, dual attainment and primal attainment are separate statements. - Raw value image G need not be convex for a convex problem. The augmented upper value set A is convex. A finite supporting slope through the optimum corresponds to equality **and dual attainment**, not merely equality of suprema.
- Shrinking x²≤r² gives equality even at r=0, but then the dual supremum is not attained. No invented positive gap at collapse.

- Farkas uses the finite polyhedral cone's closedness and projection. Its proof explains independent-subset closure, then exact separation. Gordan uses strict inequalities and a normalized nonzero certificate; the nonstrict homogeneous system is not falsely called infeasible.
