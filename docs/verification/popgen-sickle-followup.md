## Corrections

The synthetic transect is distinguished from the original map and from local causal inference. Regional qualifications in the actual Piel results replace a universal geographic claim. Clinical incidence association and the selected model viabilities are separate quantities. Birth proportions are labelled **newborn genotypes before viability selection**, rather than a measured clinical incidence. The generation-to-year forecast and unsupported modern ancestry attribution were removed.

The fixed.35 viewport clipped attainable equilibria near.5; both panels now include the entire actual range. Every reference curve obeys the actual removal/retention toggle; previously reference curves always depicted removal even when the selected curve retained malaria. Titles reflect the chosen scenario. The recurrence evolves the rare S allele directly from genotype counts, avoiding cancellation in `1−nextA`. Zero selection/zero initial S is exactly stationary; tiny remaining frequencies are represented scientifically. The t=1 boundary remains well-defined for all actual plotted starts, and no undefined all-SS zero-mean state is fabricated.
