# ALG inverse-label follow-up

The alternate D₄ mode of ALG 3.31 emitted `r^{2}^{-1}` and `r^{3}^{-1}` as column headers, which KaTeX rejects as double superscripts. The header now groups the complete element before applying inversion: `(r^{2})^{-1}` and `(r^{3})^{-1}`. The same grouping correction covers the inverse-failure readouts in ALG 3.23a and 3.30, including negative quaternion elements. Group operations, inverse lookup tables, theorem statements, dependencies and source-verification flags are unchanged.

Validation: `node scripts/check.mjs alg --static` passed for 110 items, with zero errors or warnings. `node tests/verification-alg-inverse-browser.mjs` passed all 38 focused native-control states, using one browser worker and the actual local KaTeX 0.16.11 assets through `installBrowserAssets`. Every group selector option was exercised in both themes; ALG 3.30 also covered all five integer subsets. Native element-chip clicks exercised the D₄ powered-element inverse witness, the Q₈ negative-element inverse witness, and ALG 3.31's empty-subset case. Assertions check the grouped power headers and inverse witnesses, with no runtime, page, or TeX errors after transitions.

All 38 screenshots were inspected in light/dark contact sheets, with the repaired D₄ headers inspected at full size. Readouts, screenshots and machine-readable results are saved in `/tmp/alg-inverse-followup/`; representative images are `alg-3.31-light-D4.png` and `alg-3.31-dark-D4.png`. Changes are frozen after this confirmed rendering defect; no broader review or source-flag closure was performed.
