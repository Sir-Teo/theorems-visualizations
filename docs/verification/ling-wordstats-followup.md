## Model and controls

NFC/lowercase tokens use the explicit alphabet a–z,à–ö,ø–ÿ,œ,æ,ß; curly apostrophes normalize, internal apostrophes remain in forms and are excluded from letter length. Other characters separate tokens. Ties use normalized spelling and consecutive individual ranks. All observed rank products participate in y-bound selection, including the full rare tail. Up to500 log-spaced unique ranks are drawn. Length groups use all exact occurrence counts having at least five types; no artificial connecting trend or promised monotonicity is imposed.

Unshifted and chosen-shift fits use the same selected top100/top1000/all ranks and ordinary least squares in log(count). At a fixed integer shift b, centered covariance gives exponent s and intercept lnC. The search enumerates all201 integers0…200 and refits the other parameters each time; it includes b=0, so its loss is no larger on that grid. There is no assertion of continuous global optimality, likelihood significance or out-of-sample performance. Equal-count vocabularies have exponent0 and zero loss. Fewer than two types show an explicit error and retain the actual supplied text; missing length groups show a separate no-data message.

All text/fit/toggle/integer-shift/input state saves and restores. The shift's local setter rejects raw off-grid/out-of-range/type-invalid values before runtime constraints. Native numeric thumb values are compared directly with registered state and model. Input is bounded to4096 characters by its real text field, with strict saved-state validation. Hidden custom text and the comparison-off shift are still validated. No random/opaque/drag/audio state exists.
