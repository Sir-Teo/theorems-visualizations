## Corrections and preserved scope

The old diagram contradicted its explanation by drawing separate identical vowel nodes. A single a/u node now actually supplies both separated vowels; adjacent long-vowel slots share one node too. Final associations, rather than a purported universal left-to-right derivation, are explicitly authored. Checked forms use source stems katab/daras and the attested-at forms maktabat/madrasat. The dirās relationship is specifically binyanIII; dars is the source's verbal noun. All11 lexical records are tested literally. All other root/pattern combinations still display, labeled generated/unchecked, without claiming possible Arabic words. Three literal consonants and the pattern are saved, including hidden custom input; list clicks set the registered pattern slider. Invalid text stays visible and does not get filtered into another root.

All five Indonesian and five Tagalog examples remain, now with actual source attribution. Jalan's illustrated result is corrected to the sourced berjalan-jalan; fixed ber- is shown once and not copied. Tagalog's contemplated aspect is not equated with a universal future tense; unrepresented length/stress/glottal detail is disclosed. Full/CV/CVC free play remains, but CV requires C+V, CVC requires C+V+C; an incompatible string no longer silently becomes a larger consonant cluster or the whole stem. Vowel-initial copying is limited to the Tagalog presets. No audio/random/opaque/drag state applies to these deterministic symbolic diagrams.
