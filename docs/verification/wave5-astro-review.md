## Findings repaired before acceptance

1. **Collision-rate convention:** the draft used A+ν_collision in the Lorentz rate while citing the complete phase-randomization model. Miller’s equation3 explicitly requires **Γ=A+2ν_collision**. The author corrected the helper, labels and scope, and added a numerical source-formula assertion. The prescribed collision cross-section remains an illustrative model, not a calibrated Stark-broadening inference.
2. **Contribution-weighted depth:** the mean μ belongs to the normalized attenuation kernel. For a linear source S=a+bτ, the actual intensity-contribution mean is **μ(a+2bμ)/(a+bμ)**. The author corrected both explanatory text and live readout, and added an independent first-moment integration check. In the Eddington normalization this is μ(.4+1.2μ)/(.4+.6μ); the central ray has mean1.6, while an isothermal source retains meanμ. Eddington–Barbier I=S(μ) remains correct and is not confused with an actual sharp emission depth.

The first endpoint regression additionally caught the N=1 random-walk ordinate; its vertical padding was repaired. Both full circles and their strokes now clear the actual clip.
