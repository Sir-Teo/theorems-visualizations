### Shared sample correction and consequences

Old grid used equal increments of sin(latitude), **then also reduced longitude count by cos(latitude)**. Its unweighted averages therefore counted equatorial cells more heavily per unit area. Constant longitude count now gives exactly equal cell area. Default 34×68=2,312 centres replaces 1,816 biased points. Independent area fractions and z-moments catch the original bug. Every mapErrors consumer recomputes from the corrected default; no historical/published benchmark is implied.

For example, default plate carrée mean angular distortion changes 10.8805°→16.4740° and RMS log-area scatter 0.267281→0.373773. Robinson shape 16.2000°→20.8134°, Winkel 20.5971°→22.9154°. Finite-sample scores are resolution-dependent, especially near singular polar boundaries. The adjacent 6.4 ranking UI was exercised because it consumes the shared helper; its broader source gate is not claimed as newly audited by this batch.
