## Authored model and proof

The illustration fixes equal state priors and independent noisy signals, with odd fixed informed count n1–101, accuracy q∈[.55,.95], and fixed net partisan margin m∈[−6,6]. All other uninformed voters abstain. Conditional margin D=m+2X−n has exact binomial probabilities in each state. A vote only changes the outcome at D0 or D±1, by one half under a fair tie coin. Both expected gains are calculated from these actual pivotal events; the full margin distributions show every tail, rather than a truncated count window.

For m0, D0 is impossible and Pr_A(D1)/Pr_A(D−1)=q/(1−q)>1. Thus each uninformed vote has strictly negative gain. For an informed voter, the other n−1 informed voters' tie probability is the same in both states; conditional on either signal, following it beats abstention by (q−.5)Pr(other informed tie)>0, and beats the opposite vote. These are full best replies for the balanced authored Bayesian equilibrium. Accuracy1 is excluded because it can eliminate strictness.
