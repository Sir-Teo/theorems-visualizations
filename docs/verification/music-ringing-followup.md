## Repairs and authored finite model

The old checker stopped at any return to rounds, including a return partway through its notation period. The current Framework §3.E.5 explicitly says a plain course of a static method ends at a whole-sequence boundary. For example14.14.x returns to rounds at change2 but its complete course closes at6 and is false. The helper composes a full lead's position permutation and obtains its exact order from cycle lengths; it then generates every course row. Up to120 explicitly entered changes and at most6 bells imply at most720 course changes: exhaustive enumeration of every864 permutation on4–6 positions verifies the maximum order6, also immediate from possible cycle-length partitions. There is no hidden130-change cutoff.

The old “true method” and extent checks conflated unique rows with the general truth definition and ignored permanently fixed places. Now fixed places are found over the complete course, the effective extent is its factorial, and every row occurrence is counted excluding only the final closing row. Let q be the minimum count over every possible effective-stage row, including count0 for unseen rows. The touch is True exactly when every count is q or q+1: q complete extents plus distinct residual rows. Complete means all effective rows have equal counts. A separate full-stage extent-once indicator avoids implying that an effective-stage repeated extent exhausts all n! nominal-stage rows.

Source Plain Bob exactly matches the printed25-row table and has24 distinct rows/three8-change leads. Plain hunt closes after8/10/12 changes on4/5/6 bells. A group-generation argument alone cannot certify a Hamiltonian course; the item now uses the actual row inventory. Place lists are strictly increasing/distinct/in range, every unfixed position has an adjacent partner, and an identity is rejected as outside this adjacent-change illustration. Inferred external places and comma abbreviation are deliberately unsupported and clearly disclosed.

The original fixed0–48 slider and increasingly compressed whole-course braid are replaced by a saved0–720 change control, explicitly clamped to the current course length, and a readable window of at most13 rows. The full course is always checked. Clicking a visible row enters that actual global change index. Invalid text shows an error, disables sound, and replays as the same error rather than silently reusing stale data. Both the selected row and every visible row are offered as explicitly named audio actions; no unseen truncation of a “whole composition” is claimed.

Synthetic audio uses an authored diatonic register, bell1 highest, H8 amplitudes1/h, mono44,100Hz,0.1s notes,0.08s gaps between rows,10ms ramps, raw bound0.12, voice1/master0.9/limiter. Every event follows the actual selected/window bell order; all partials are below Nyquist. It does not model bronze bell spectra, swing timing or a record performance.
