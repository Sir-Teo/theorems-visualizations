## Exact convention mapping and repairs

The source's Eq6, on columns ordered `(H,X,Y,Z)`, has spatial rotation `Rz(theta) Rx(-alpha_source)` and translation `(a cos(theta), a sin(theta), s)`. With permutation order `(1,2,3,0)`, moving H to the last slot, it is exactly the modern classical transform **`A(theta,d,a,alpha_modern)` with `d=s` and `alpha_modern=-alpha_source`**. Angle and a are unchanged. The source's consecutive-pair indices are replaced by the modern serial-robot indices stated in the content. The candidate does not claim that its modern table or frames are reproduced from the original.

For modern `Z_i=Rz(theta_i) Tz(d_i)`, `X_i=Tx(a_i) Rx(alpha_i)`, the modified prefixes are `B_i=X_(i-1) Z_i`, `X_0=I`; their product requires the **terminal fixed tool transform X_n** to equal `A_1 ... A_n`. Intermediate frames move when the convention is switched; the tool pose stays fixed. Dropping the tool is demonstrably wrong for nonzero terminal geometry. No blanket assertion equates an uncorrected modified end frame with the classical tool frame.

The original prose's unsourced modern-industry generalization and statement that the full original was unread are replaced with the actual source arguments and bounded modern mapping. Closed-loop closure is a constraint, not an automatic consequence of choosing four numbers; six lower-pair types and decompositions do not mean four independent freedoms per joint. The toy explicitly shows an authored revolute chain; editing a,alpha,d changes its geometry. Its modern a is a signed directed offset, not a negative physical distance. Parallel/intersecting/coincident axis choices can be nonunique.

The old widget kept a mutable four-row P array outside registered state. Only the currently selected row's four thumbs were saved, so edits to other rows could vanish on replay; shrinking the chain while another row was selected also mixed row and thumb values. The candidate uses **16 individually registered exact-tick controls**, shows the selected row's controls, and saves all inactive rows. Stored link selection remains1–4 independently of active count; an inactive row is clearly labeled and never silently changes an active row. A local setter guard rejects off-grid saved values before the shared runtime setter can sanitize the thumb. All17 DOM ranges are compared numerically with registered/model values, including hidden/inactive rows. No shared runtime was changed.

The scene's actual yaw/pitch now have a validated opaque saved component. Rotation changes by real background dragging and survives exact replay. Reset restores all rows, selectors, count and camera. The plotted view fits actual projected links, joint-axis stubs, frame arrows and labels, giving readable geometry at320px and keeping complete strokes inside the panel at extreme parameters or rotated views. View scaling/arrow lengths are explicitly illustrative.

The source, matrix and regular control checks above do not certify that extreme camera state. The flag remained true during the repair.

This instance-local wrap preserves the equivalent orientation, including at either full-turn boundary. The shared scene/runtime is unchanged. Exact in-range values, including both endpoints, are returned untouched by the local wrapper.
