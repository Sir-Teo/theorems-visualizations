# Unwired uploaded-curve bounds prototype (source/model proposal)

This proposal starts from accepted root `90e2e8166a8553008490c67f68ec5fbc862c2045` and the independently reviewed enclosure proof `573a9a3fd91e24f15e1be30c2d47739e100ad5a6`. It adds private files only. The accepted XY runtime, original SceneEdges/shaders, assets/data, static fixtures and runners remain unchanged. No observer, selected-shard/full oracle or browser wiring is included. No performance or current-data fit claim follows.

## Deliberate counted mapping extension

Root authorized extending the initial 16-byte/path design to **24 bytes/path**: four Float32 extrema (16) and two Uint32 original start/count values (8). One reserved ArrayBuffer has both typed views; no per-point map, per-path object copy, new membership array or separate staging store is retained. This catches well-formed in-place changes to the mutable original range mapping without hashing it, freezing/mutating original objects or hiding additional storage in bookkeeping.

The owner is explicitly `curve-bounds-and-mapping`; resources expose separate `curveBoundsCPU` and `curveMappingCPU` counts. No existing XY-classifying observer is used. Future reserve-observation wiring must classify the new owner distinctly and count both views once through their shared backing. Existing 4096 bookkeeping and one fixed 262144-byte CPU/GPU scratch pair remain accounted. Frozen 23,364-path storage is 560,736 bytes, saving 8,731,048 versus 9,291,784 XY bytes. Conditional original-peak + metadata + bookkeeping + scratch envelope is 55,426,696, not an observed proposed peak; current-data fit remains unmeasured.

The descriptor and every liveness/flush check require the original range-array identity/length, captured point/segment counts and per-path numeric start/count snapshot, plus a complete contiguous partition/startSegment check. A numerically changed mapping is rejected even if it remains well formed and preserves totals. Replacing the array also bypasses optimization. Replacing a range object with the same relevant numeric mapping is semantically equivalent; object identity is not separately copied. Original range.length and shader arc/ID data are validated at upload; later membership uses only start/count, while those original GPU fields remain untouched. Original path coordinates and ordered style-ID lists retain the existing original-source immutability premise; no new full copy is hidden.

## Explicit source changes

`map-curve-bounds-runtime.mjs` subclasses the existing private XY class and directly calls the original SceneEdges upload/bind methods. The source/model comparison enumerates exactly seven overrides: optionalResources, upload, descriptor, live, supported, box and bind. Constructor/budget wrappers, events, optional reserve/drop, original construction-stream comparison, union-frame ownership, fixed scratch and destroy remain inherited. The original shader methods remain byte-identical. Two new pure stream/mapping helpers and the separately enumerated math/validator exports are proposal code, not hidden renderer rewrites.

Upload reserves before allocating the single metadata buffer. Actual Float32 XY is scanned inclusively through each range's final endpoint, with no padding interpreted as geometry. Validation covers original point/texture/range partition, safe signed shader indices, nonempty original path correspondence, finite coordinate/arc/ID lanes and endpoint-flag classification, finite uploaded half-join envelope and supported coordinate/J limits. Zero-segment ranges remain indexed and emit nothing. CPU upload arrays are borrowed only during upload and not retained. Metadata denial/missing/invalidity uses the original full-group path.

Curve boxes use the reviewed same-associated magnitude fold with binary64 nextUp after every addition, followed by outward center/radius/device-pixel/guard arithmetic and final integer bounds. The half/style radius, Float32 k/translation, full primary viewport guard and original supported domain remain those of the accepted proof. There is no regrouped uninflated 2X+2Y sum. Unknown geometric bounds include the whole original range; untrusted association bypasses whole-group optimization. Conservative boxes do not re-prove a wider shader/raster domain.

The stream preserves original cached endpoint coverage, style-ID order, contiguous original indices and repeated occurrence multiplicity. It increments full original segment count even for culled ranges before comparing original group.count. It never retains a new full membership list. Shader endpoint culling, style clipping/scissors, MAX mask, one composite and fixed scratch flushes remain original. The new liveness check explicitly requires actual budget ownership of both model and group, plus the counted mapping check; a deleted-but-truthy group handle cannot enter live replay. Ownership failure before an optimized bind aborts rather than binding a released buffer.

## Bounded source/model evidence

The final comparison passes with **22 actual-class fault contracts and 6,433 independent checks across 16 additional model cases**. Against the same canonical input, the unchanged XY class retains its one release-only ownership failure; the proposed class passes all 22 safety expectations. No fault assertion is relaxed. Both roots receive the same test-only startSegment=0 field needed to make the older synthetic fixture conform to the real builder. Exact reverse reconstruction permits only that fixture field, factory-loader selection and the recording-GL import URL. The original negative probe file remains byte-identical.

The independent cases include 256 exact ordered/multiplicity/full-count inventories; 3,528 comparisons with actual old computed segment boxes; the supported association counterexample; signed-zero/subnormal/exponent boundaries; actual original-builder extrema/padding/zero ranges; unsupported upload/domain/ID/flag/arc/range cases; geometric unknown/include; full-count accounting when whole curves are rejected; changed/replaced mappings; a shared-backing identity assertion; explicit 24-byte storage reservation; and a well-formed mapping change during the first prefix. That last case aborts without original replay or composite. Pre-bind mapping failure uses the unchanged original group buffer; no guessed new mapping is emitted.

The source comparison enumerates all seven overridden functions, hashes both versions, confirms no additional prototype overrides, and verifies **64 existing source files byte-for-byte**. The new math exports are nextUp64, nextDown64, curveDomain, validateCurveUpload, fillCurveExtrema and curveBox. The two additional runtime helpers are trustedCurveMapping and visitCurveMembership. This is the complete new executable surface; there is no hidden shader or renderer patch.

The actual classes run with deterministic recording GL and existing SceneBudget ownership, not native rasterization. All original-priority denial, metadata failure, live replay, stale/released invalidation and cleanup contracts are exercised. The release-only case specifically retains its stale-abort/no-replay requirement and now passes through the explicit actual group ownership check. Parent/source path and ordered style-list immutability during a synchronous frame remain original-source premises; only the numerically relevant mutable range mapping receives the additional counted snapshot. Private metadata arrays are populated once and remain privately owned until release; deliberately marking corruption, replacing views or producing unknown extrema triggers bypass/include as documented. This does not claim to detect an adversary that maliciously rewrites private snapshots and metadata together.

## Current-context arithmetic is not proposed fit evidence

Root subsequently supplied a separate actual current-light outcome: scale 4 has 1,306,418 points and 1,282,463 segments, giving 23,955 paths. The accepted XY branch admitted 10,455,440 metadata bytes then dropped optional ownership under original-priority pressure before frame 0; all twelve context draws used fallback, with 125 original binds and zero optimized visits per main draw. Its measured original peak is 59,375,200 and alternate peak 59,518,092. Those current measurements are distinct from this proposal and are not re-run or independently accepted by this model work.

For the new counted representation, 23,955 × 24 = 574,920 bytes; adding 4,096 bookkeeping and 262,144 scratch gives 841,160 optional bytes. The **conditional** same-original-history envelope is 59,375,200 + 841,160 = 60,216,360, leaving 3,783,640 below 64M. That is an owner arithmetic envelope, not a measured proposed peak, current fit guarantee or evidence of optimization. It must remain separate from the measured existing fallback peak 59,518,092.
