## Corrections

3.9 separates multiplying likelihoods from repeatedly multiplying posterior priors. The chosen model applies a flat prior once in **positive restoring feedback**; transformed densities now divide by Z=Phi(mu/sd), conditional quantiles invert that same branch and remain finite/positive instead of using untruncated Gaussian quantiles. Combined GLS weights use the exact equicorrelation inverse; no fallback silently changes the covariance. The main marker is the conditional median rather than F/mu being labelled ECS. Actual probabilities/quantiles retain off-screen mass; finite0–8K display is declared and interval tails carry arrows. Corrects paleoclimate's one-sided very-likely lower bound instead of pairing it with an extremely-likely upper bound as if they formed a two-sided interval. Removes universal narrowing claims and distinguishes chosen distributions from AR6's expert synthesis. Handles occupy separate small rows below the axis, so coincident centres remain individually draggable. Dynamic density ranges include all visible curves.

4.7 replaces an unchecked tridiagonal steady solution with a symmetric finite-volume restoring-plus-diffusion solve checked by LDL positive pivots at a scale-relative roundoff tolerance. Unstable/near-singular configurations are explicitly marked and omitted from response curves/bars, rather than drawing negative/unstable algebraic solutions as warming. Each modified model is checked independently. The “no heat transport” variant now actually usesD=0 instead of0.02. Local negative restoring alone does not prove global instability; diffusion can stabilize some profiles. Arctic averaging uses fractional grid-cell cap areas at66.5°, and the denominator is the symmetric-planet mean. Fixes dated observational scope and distinguishes dry-temperature diffusion from real latent transport. All stable comparisons, signed feedback profiles and bars determine full ranges. The linear energy-balance model remains explicitly illustrative, not a fit or forecast; large computed warmings are outside a realistic small-perturbation interpretation.
