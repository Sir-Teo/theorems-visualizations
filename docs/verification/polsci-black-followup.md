## Corrected model and interaction

The old editable-height example declared strict rankings while allowing equal heights, used the number of local maxima as its single-peakedness test, and promised that bending one curve would produce a cycle. The new model uses actual strict permutations throughout. Adjacent swaps reach all 24 rankings for each member, while keeping other members fixed. Custom edited rankings are saved and validated as three dense permutations, independently of the selected member.

Single-peakedness is checked over every ordered triple on the fixed A–D axis: the middle alternative must not be ranked below both extremes. For strict orders this is equivalent to strict ascent/descent around the unique peak. Every pairwise margin is an exact integer computed from actual rankings, including +3/+1/−1/−3. Every possible Condorcet winner and every three-cycle is checked. The median label appears only when all rankings are single-peaked. A failed domain restriction does not imply a cycle or absence of a winner. Curves use explicit ordinal heights4,3,2,1; connecting lines create no intermediate motions or cardinal utility claim. The displayed median proof counts the actual majority on each side and establishes a unique winner within this stated domain.
