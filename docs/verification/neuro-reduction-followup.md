## Corrections and limitations

The retained equations explicitly define the simpler n-only mathematical closure. They no longer claim exact collapse or a universally valid slow manifold. The fixed coefficients .89 and1.1 are chosen atlas illustrations, not an unread original parameter fit. The optional line uses the same full-model run that it is compared against, so its fit is not an independent prediction. Its actual sample interval is stated: from two milliseconds before the first detected spike, or3ms without a detected spike. A nearly constant cloud now has no fit; it falls back explicitly to the chosen line instead of displaying unstable coefficients/R². Zero current is now accessible. Full/reduced count disagreement is retained visibly, rather than captioned as guaranteed waveform agreement.

The full and reduced models start from the same V,n, but the substituted h is different and need not preserve rest. The visible line and both voltage traces determine their windows. Gate surrogates outside0–1 are counted without clipping; none occurred along the tested41-current runs, but the displayed line extends beyond physical h and synthetic diagnostics independently verify failure reporting. Mean intervals with fewer than two events are unavailable, not NaN or zero. All counts/intervals are finite60ms observations. The existing shared integrators are unchanged; endpoint-sampled input is resolved at dt.02ms, and observed onset-time discretization decreases under refinement. No global error bound or biological fit is asserted.
