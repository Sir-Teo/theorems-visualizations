## Event-study derivation and repairs

For a declared excess-return benchmark b, `AR=(r_i−r_f)−b`, with `b=alpha+beta(r_M−r_f)`. Average AR across N observations, then sum over time for this illustration's arithmetic CAR. This is not compounded wealth, and a return residual is not automatically a causal effect of the event. Sorting by assigned future effects does not supply a real-time trading signal.

The five assigned effect multipliers are−1,−.4,0,.4,1; largest absolute effect is1–6 percentage points. The zero baseline is day−20. There are exactly40 increments and41 retained times through day20. Each increment's group-mean error is drawn as `1.5 Z/sqrt(300)`. This is exactly the law of the mean of300 independent N(0,1.5²) errors; there is no claim to have generated/read300 original firms. Independent errors give daily mean variance `1.5²/300` and terminal noise variance `40*1.5²/300`. A common component c would leave variance `var(c)+1.5²/N`; averaging does not remove it.

The schedules are explicitly chosen. Jump: all J at day0. Drift: .6J at0, then .02J on each day1–20. Early: .035J on each day−10..−1, then .65J at0. All finish at expected J. The sample adds cumulative noise, so its terminal value need not be J and a flat expected path does not force a flat sample. Both205 sample ordinates and205 expectation ordinates are retained. The plot bounds include both full sets, with stroke padding. The old ±5 frame clipped offered±6 effects; the repaired bounds adapt.

## Fund-model derivation and repairs

For a selected subset, `a_i=mu_g−f+s Z_i`, `alphaHat_ij=a_i+(sigma/sqrt(H)) Z_ij`, all standard-normal draws independent. This is an authored distribution of annual arithmetic benchmark-relative estimates, not an index wealth simulator. Thus `m=mu_g−f`, `V=s²+sigma²/H`, `P(alphaHat<0)=Phi(−m/sqrt(V))`, and `Cov(alphaHat_i1,alphaHat_i2)=s²`, giving population correlation `s²/V`. Positive m makes the negative-alpha fraction decrease with H; negative m makes it increase; zero m gives.5. With s>0 its infinite-horizon limit is `Phi(−m/s)`; with s=0 it tends0/1 for positive/negative m, or stays.5 at zero. A fee is an additive alpha decrement in this model, not a full implementation/compounding cost model.

The model controls are f0–2, mu_g−1–1, s0–3, sigma1–8 annual percentage points and integer H1–15. The source panel has five fixed SPIVA observations.
