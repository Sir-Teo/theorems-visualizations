Strong new-pair MAC unforgeability differs from fresh-message unforgeability for nonunique tags. Deterministic signing alone is insufficient for equivalence unless verification has exactly one valid tag. The book's strong definition is consumed by its composition proof; weak fresh-message unforgeability alone does not rule out a new tag on the challenge ciphertext.

The uniform birthday law is a model, separately distinguished from a deterministic sequence of truncated SHA outputs. HMAC security is not inferred merely from collision resistance. Poly1305's clamped-key length-dependent bound is not the generic exact2^-128 guessing bound.
