## Corrections and independent reasoning

**SFE.** Zero-probability letters are omitted, dyadic midpoints use terminating expansions followed by zeros, and the singleton shorter variant correctly uses the empty word. The former `slice(-0)` produced a spurious digit. Arbitrary 1e−12 length, rounding and containment tolerances are removed. Stored binary64 bar values are converted to their exact integer ratios and normalized exactly; integer shifts/divisions determine lengths and midpoint truncations. Prefix and containment checks are exact. The plotted coordinates and average/entropy labels remain rounded. Full codes appear in the readout, with long canvas labels abbreviated. Removing the extra bit is described as potentially failing, not necessarily failing at every distribution.

**Arithmetic coding.** The former shortest-point construction did not supply the claimed prefix property and could collapse narrow intervals or encode impossible letters after silently flooring their probability. A code now represents an entire dyadic cell inside the final message interval. Length N and the model are explicit side information; variable-length framing is excluded from the ideal bound. Integer rational interval updates retain tiny positive widths. The chosen cell has minimal length: a cell's width cannot exceed the message width, and the first admissible mesh level is tested exactly. A mesh of at most half the message width always supplies a contained cell, proving the stated less-than-two-bit overhead. Decoding uses that cell's midpoint and the same known N/model, with exact integer comparisons.

Input is no longer lowercased, filtered or truncated silently. Invalid/overlong messages and zero-probability letters show explicit failures. A deterministic fixed model can use the empty word when N is known. Displayed common digits use half-open interval endpoints, without the old `hi−1e−15` adjustment or 40-bit decision cap. The final magnified row shows the actual green code cell; message labels have a visible left margin. These common digits illustrate interval geometry rather than claiming to implement every practical renormalization operation.
