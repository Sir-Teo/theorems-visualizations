For rate interval [a,b]=[khat−w,khat+w], intersect with the strictly positive elimination-rate domain. If b≤0 there is no compatible positive-decay half-life. If b>0 the lower endpoint is ln2/b; the upper endpoint is ln2/a when a>0, and unbounded otherwise. Thus the transformed set is closed at finite valid endpoints and open at infinity: [ln2/b,∞). A nonpositive point estimate has no positive-decay half-life even when part of its interval is positive. The readout now states those cases explicitly and labels inference nominal.
