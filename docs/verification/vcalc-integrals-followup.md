## Corrections

The bounded-measurable-integrability statement now specifies a finite-measure
set. Pointwise closure of measurable functions is distinguished from convergence
of integrals, which needs the stated uniform bound. The counterexample
`n*1_(0,1/n)` explains why the hypothesis matters.

The display previously used extrema from 20,000 samples as if they were the true
infimum and supremum on every interval. The replacement computes actual cell
extrema. For the smooth wave, its derivative reduces to
`4*cos(4x)^2 + cos(4x) - 2 = 0`. For the chirp, extrema occur at the explicitly
known sine phases. The first interval has infimum zero and supremum one,
regardless of its width. Removed the artificial constant phase below x=1e-6;
the function has its stated value for every positive x and value 1/2 at zero.

Range-band measures still use midpoint sampling. They are explicitly labelled
as estimates: the blue bracket encloses the sample mean, and does not certify
the integral. The rational example uses the exact null-set argument, independently
of the illustrative finite set of dots. Removed the unproved blanket 1e-3
accuracy claim. Sequence mode changes the horizontal label to n and restores m
when leaving that mode. Readout formula rendering was checked visually.

The Gaussian discs now use `pi*(-expm1(-R²))`; the square uses an 800-panel Simpson
integral. This avoids the slight spurious overshoot of pi from quadrature of
the radial disc integral and accurately describes which values are numerical.
