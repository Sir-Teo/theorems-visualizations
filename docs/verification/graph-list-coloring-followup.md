## Corrections and mathematical review

**List definitions and editing.** The source definition quantifies over every size-k assignment, rather than a selected palette or sample. The standard inequality χ≤ch and greedy Δ+1 upper bound were checked directly: identical lists yield ordinary colourings; at most Δ previously used neighbour colours can exclude colours from any list of size Δ+1. The K₃,₃ lists are exactly the source's three pair-lists on each side. The K₂,₄ preset has two disjoint pair-lists on its two-vertex side and all four cross-pairs on the other side, so any choices on the first side block one opposite vertex. The odd cycle's identical two-colour lists fail for the ordinary chromatic reason, while C₄ remains colourable. The caption now distinguishes these cases.

The palette and requested random-list size controls formerly could disagree: e.g. four requested colours from a palette of three, or a reduced visible palette while stored lists still used hidden colours. Raising list size now raises the palette if necessary; reducing the palette removes hidden colours and reduces an excessive requested size. Preset loading also clamps the requested size when it resets the palette; programmatic slider changes do not invoke their user-change callbacks. Actual list sizes are still reported. Empty lists remain allowed in the editor and correctly yield an uncolourable assignment, rather than pretending to be a size-k counterexample.

The two reviewed list displays now use a dedicated bounded enumeration returning an actual colouring witness, an exact completed count, a count lower bound at the count cap, or an unresolved work limit. A work limit with no witness is not a completed failure; positive partial counts remain lower bounds. Red failure styling is reserved for completely checked unsatisfiable assignments. The hill-climb skips unresolved scoring trials, retains an existing display if no resolved candidate was found, labels its capped scores, and reports work-limited trials.

**Alon's theorem and the separate explicit picture.** The old entry used a quantitative half-logarithmic asymptotic statement, a vague “1990s” credit, and an explanation suggesting degree roughly 4ᵏ sufficed for the cited 1993 argument. The sixth edition actually states the qualitative threshold theorem. Its statement and credit are restored exactly in meaning: for each target k there is a finite average-degree threshold forcing choice number at least k. This is not a claim that no later stronger bound exists.

The proof sketch follows the primary 1993 proof: pass to a bipartite subgraph of high minimum degree, choose random lists on one side, obtain many vertices on the other side whose neighbours represent every possible list, then choose that other side's lists and union-bound over colourings of the first side to prevent all extensions. In the paper, a sufficient explicit condition for ch(G)>s is d>4·C(s⁴,s)·ln(2·C(s⁴,s)); this is substantially different from a bare 4ˢ estimate. The diagram instead gives a deterministic obstruction on Kₙ,ₙ, n=C(2k−1,k), by assigning all k-subsets on each side. Any successful colour partition would have to put at least k colours on each side of a palette of size 2k−1. Thus it fails for every partition, as the elementary general proof shows. The plotted ½log₂n curve is labelled a reference for that construction, not the general theorem's explicit bound or its proof.

**Edge-list conjecture.** The statement now specifies finite **loopless** graphs/multigraphs; loops would make proper edge-colouring impossible. Vizing's Δ or Δ+1 assertion is explicitly limited to simple graphs. The previous caption claimed every assignment with k<χ′ fails. That is false: on C₅ assign a different singleton colour to each edge; the assignment is colourable although k=1<χ′=3. Identical lists of length k<χ′ fail, while other assignments may use a larger union of colours and succeed. This correction also applies to search results below the ordinary index.

The former scope said the conjecture was “verified here” by random search. It now says that only particular assignments in a bounded palette are checked, which does not verify choosability even for a displayed graph. Capped score ≥300 is no longer presented as exactly 300. A completely checked failing assignment at k≥χ′ would require independent confirmation; the UI no longer proclaims a counterexample merely from an unresolved solver result. A positive search result supports only the current finite trials.

**Directed kernels.** Independence and absorption were checked against the source's outgoing-arc convention. In a directed triangle a singleton leaves its **successor**, not its predecessor, unabsorbed; this wording is corrected. The caption now identifies the selected set by its actual green fill, rather than claiming it has a selection ring. The statement and the ancillary existence claims explicitly concern finite digraphs. The finite acyclic construction selects a sink, removes it and its predecessors, and repeats. Kernels in every induced subdigraph, together with the strict out-degree/list-size bound, provide a **sufficient** list-colouring criterion, rather than an unspecified “exactly what is needed” equivalence.

For the finite no-directed-odd-cycle claim (Exercise 36), the general argument can be given without relying on finite samples. In a strongly connected component, the parity of a directed path between fixed endpoints is well defined: appending a common return path to two paths with different parity would give an odd closed directed walk, which contains an odd directed cycle. Thus each nontrivial strongly connected component is bipartite. Take a sink component and one bipartition class; each vertex in the other class has an arc into it. Remove the chosen class and all its in-neighbours, and apply induction to the remaining graph. The union of the chosen class with the inductive kernel is independent (the component was a sink and all incoming neighbours were removed) and absorbs every removed or remaining outside vertex. A singleton sink component is the same induction step. This supplies the finite existence reasoning; the test enumeration does not prove the theorem for arbitrary sizes.
