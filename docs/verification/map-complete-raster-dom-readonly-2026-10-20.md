The final635 `drawImage` samples the cache at CSS width/height times `s=k/cache.k`. Its translation is **the production physically rounded translation**, not the unrounded affine transform used by the rejected split compositor:

```
x = round((tx - cache.tx*s)*dpr)/dpr - cache.pad*s
y = round((ty - cache.ty*s)*dpr)/dpr - cache.pad*s
```

A proposed presentation must preserve those x/y exactly, set the cache canvas CSS dimensions to `cache.width`/`cache.height` (not backing dimensions divided by DPR, which differ when ceil applies), use origin `0 0`, and apply `translate(x,y) scale(s)` in that order. Thus source physical pixels map by `cache.width/backingWidth*s` and the analogous vertical factor, matching the destination rectangle algebra. CSS sampling may still differ; algebra is not a pixel-equivalence proof.

## What existing pixels establish, and what they do not

The split compositor's136 complete-picture pairs across8contexts compared its **split/current-text** output to the complete direct `_paint()` at matching transforms (`tests/map-canvas-compositor-native.mjs:5,12–15`). Its .901/1.099 hit cases and direct/fallback comparisons do not certify CSS scaling of all cached words through .6–1.8. Final93f033a adds focused34 comparisons and resize proofs; neither changes that scope. The previous rounded-translation failure was relative to direct current geometry in the split design; it does not authorize replacing production's rounded presentation in a cache-preserving design.

A correct new assessment needs **two references**, both complete and unmasked: (1) unchanged production `_draw()` given the identical cache birth/history, source cache bytes and offered transforms; (2) current complete `_paint()` at each identical transform, retaining the existing mean<2/255 and above20/255 fraction<2% limits wherever those gates are required. The latter exposes inherited cached-text/stroke drift as well as new CSS error. If production itself exceeds the direct reference at a wide ratio, record that baseline finding; do not silently weaken the bound, hide text, or claim the old136 images cover it. A whole-raster proposal failing the required direct bound must be rejected or returned for an explicitly assigned scope decision.

Native text must actually remain present and readable. Attaching a previously detached Canvas can affect browser raster/compositor behavior; subsequent cache construction while attached could differ from production's detached text painting. One conservative experimental invariant is to detach the **same** cache before rebuilding through the original path, then attach it only after construction. This preserves source rasterization context without an additional image copy, but attach/detach costs and browser behavior remain unmeasured. Cache bytes must be checked before/after attachment; no assumption of internal zero-copy is justified.
