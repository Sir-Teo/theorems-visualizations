## Models, hypotheses and numerical scope

All states are complex pairs [real, imaginary]. Actual Hadamard butterflies, reversible XOR permutations, reflections, controlled unitaries and conditional shifts evolve the whole state. No curve is substituted for that evolution, and no evolved state vector is silently renormalized. Raw norm is displayed. Probability sampling normalizes nonnegative computed squared weights by their sum, keeping numerical norm drift separate. Plot/moment calculations distinguish amplitudes, probabilities and frequencies.

1. **5.1:** three input qubits, arbitrary eight-bit truth table and selected circuit stage. Phase target |−〉 factors out. Full signed pipeline and selected amplitudes implement Hadamard character cancellation; coherent querying does not expose an entire truth table in one measurement.
2. **5.2:** actual four-amplitude input/target circuit, all four Boolean functions, all intermediate stages; one oracle call starts at the oracle stage, not at preparation.
3. **5.3:** four-bit constant/parity/nonlinear-balanced examples and an explicit one-marked promise violation. XOR translation preserves balanced cases. The exact deterministic comparison is separated from easy randomized bounded-error classification.
4. **5.4:** four-bit zero-offset f(x)=s·x. Classical unit-vector queries reveal bits in LSB-first order; remaining candidate count is 2^(4−k). An unknown affine offset would change a simple classical upper-bound procedure, so it is excluded rather than mislabeled.
5. **5.5:** eight-qubit actual joint state, f(x)=min(x,x XOR s), nonzero four-bit s. Marginal law is computed before sampling. Integer XOR row operations over F2 report actual rank and nonzero candidates; zero/repeated equations still count as queries. Seeded traces are not guaranteed to span. The ideal failure bound is a supplied union-bound argument for independent Born samples, distinct from a deterministic pseudorandom realization.
6. **5.6:** actual 16-amplitude Grover iterations for all M=0..16 and finite r=0..12; separate sine-law check. Phase-oracle queries are counted separately from known gates and an optional extra verification query. First peak assumes known positive M. M=0 cannot succeed; M=N needs no amplification. Continued iterations overshoot.
7. **5.7:** actual complex 2D preparation A and reflection products, adjustable p/phase/rounds; A, A† and good-space phase calls are counted separately. Coherent invertibility is required. The angle is computed with atan2(sqrt p,sqrt(1−p)) to retain accuracy near both endpoints, rather than losing the small complementary amplitude through asin(sqrt p).
8. **5.8:** actual two-/three-qubit ancilla circuit; controlled phase U=diag(1,exp(i alpha)), Re/Im choices, and pure-state swap test. Seed/shot controls determine the actual Bernoulli trace; exact law, frequency and model-predicted standard error are distinct. No confidence guarantee is attached to one trace, and zero shots has no estimate/SE. Controlled-U access is assumed explicitly; an arbitrary unknown uncontrolled black box is not presumed controllable.
9. **5.9:** coherent coin-H then left/right shift on a fully covered finite light cone, t≤40; no absorption, wrap or boundary loss. Initial relative phase is retained. Independent fair-step classical probabilities are evolved alongside, and all means/variances are actually computed. A finite simulation does not establish an asymptotic theorem or an oracle-query speedup.

All seeded experiments use a declared deterministic 32-bit LCG, reproducible from ordinary seed/shot controls; there is no hidden sample history. State replay can reconstruct the entire trace. Bit ordering is input/ancilla for oracle circuits, with ancilla in the low output bits; classical BV query display reveals LSB first. All quantities here are dimensionless amplitudes, probabilities, integer gates/queries/steps or angle fractions, not physical laboratory timing.
