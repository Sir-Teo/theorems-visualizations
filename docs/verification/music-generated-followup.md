## Repairs and mathematical scope

8.5 previously asserted a converse identifying arbitrary Myhill scales with maximally even sets. The concrete counterexample {0,1,2} in Z/12 has generic spans1/10 and2/11, so each interval has exactly two sizes while maximal evenness fails. The item now distinguishes these properties and computes both. Its floor-scale theorem explicitly assumes integers c>n≥2. For generic k, summing all cyclic spans gives ck, forcing both floor/ceiling values when ck/n is nonintegral; the exact number of larger spans is ck mod n. Thus the floor construction has Myhill's property exactly when gcd(c,n)=1. This is a supported claim with its own finite proof, not closure by deleting the uncertain converse.

All preset spans and multiplicities are exact integer computations. The octave wrap is included. The selected interval is explicitly clamped to n−1 for smaller examples. Random scales now come from a visible integer seed, saved by the existing state registry, rather than hidden unregistered Math.random state. The chart accommodates all six sizes reachable by seeded seven-note scales. Every displayed scale note plus the closing octave is synthesized.

8.6 previously counted repeated rational notes as zero-length gaps, labelled a rounded rational as the pure fifth, and silently truncated up to60 displayed notes to16 in audio. Exact-formula presets now have a separate saved choice from the custom slider. Custom thousandth-cent values use numerator/1,200,000; residues, duplicate detection, period and gap equality use integers. Endpoints0 and1200 produce one distinct position and one positive octave gap. Repeating the12-TET fifth beyond12 generated points leaves12 equally spaced distinct positions. Zero gaps are never counted.

The pure-fifth, pure-third, pure-fourth and golden-formula presets remain floating evaluations of exact irrational formulas, explicitly disclosed with a 1e−11-octave grouping tolerance for n≤60. The90-digit oracle validates their full order and gap inventories. The widget independently reports the generation-to-rank automorphism j↦Mj mod n rather than calling every two-gap count well formed without testing the order. Equal spacing is labelled degenerate, and repeated generation cannot pass the n-distinct rank test. The exact pure-fifth nondegenerate sizes through60 are2,3,5,7,12,17,29,41,53.

Native slider events choose custom mode, while programmatic state restoration preserves the saved formula preset. This prevents restoring a changed custom value from silently overriding a subsequently selected pure-fifth preset. All distinct displayed notes, including n=60, plus the octave play; Stop audio is explicit. Audio is an authored H8 spectrum with1/h amplitudes, mono44,100Hz,0.25s notes,0.02s gaps,10ms ramps, raw bound0.12, voice gain1, master0.9 and limiter. Every harmonic is below Nyquist throughout the offered octave.
