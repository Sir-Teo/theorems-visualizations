# Remaining pilot review sessions

**Exact candidate:** history and literature 0.1.1. Use the current builder's content/artifact digests before recording a receipt. These are session instructions and an empty evidence record, not completed reviews.

## Independent source and language review

Inspect the source selections, source/reuse decisions, claims, editorial context, answer guides and transfer rubrics. Identify the reviewer and their actual role. An AI reviewer must be labeled as AI; it is not a recruited historian, language specialist or lawyer. Retain access stops, including the Koto timeout. Record unsupported claims, specific repairs and any review dimension that the evidence does not cover. Recheck changed versions before approval.

## Screen-reader task review

Use an actual screen reader and record its version, browser, OS, input method and observer. On each pilot:

1. Locate the page title and navigate headings to source cards; distinguish quotations from editorial context and inspect source details.
2. Use the skip link, task/lens control and evidence/category controls. Confirm labels, option announcements, focus order and the source language announcement where supported.
3. Trigger feedback or change the reading lens. Record what was announced and whether it was comprehensible, including repeated changes.
4. Enter a note, navigate a source anchor, share selections and export notes. Confirm private notes do not appear in the shared URL and focus does not jump after a delayed clipboard failure.
5. Reset the current revision and inspect the saved-state announcement. Check the denied-storage alternative. Record whether the reader can recover earlier notes by export.

Do not infer success from DOM attributes, automation or a screenshot. Record actual observed announcements, barriers, help supplied and repairs. A pass applies to the recorded task/platform, not universal accessibility certification.

## Formative learner observation

Use consenting readers who did not author the lessons. Collect only a participant code and relevant task context; no unnecessary identifying information. Let the reader use the existing text and guides, recording any extra help. This is a small formative study, not a claim of measured learning efficacy.

History prompts:

- Explain what the conditional phrase supports and whether the two documents establish Mexican acceptance.
- Explain whether a newspaper repeating the message automatically provides independent corroboration. Name the provenance information you would seek.

Literature prompts:

- Pick one English wording or punctuation difference and support two possible readings.
- Assess the claim that the English plural proves what Bashō saw. Separate observation from an original-language or biographical inference.

Record the reader's explanation, cited evidence, task completion, confusion, assistance, transfer response and resulting changes. Do not supply the expected answer before observing. A reviewer should assess whether the stated learning task was accomplished and identify unresolved barriers. If repairs change the content or interface, bind subsequent review to the new artifact.
