02

Explore the evidence

Read all three comparison guides

Count the changed factors

A’s position and both orientations change; B’s position stays fixed.

Why is this not a single-variable causal experiment?

  • Three planned spatial factors change, even before any real performance occurs.
  • Actual timing, delivery, access mode, viewpoint and order could vary too.

An authored control is not a measured constancy.

Mark a prediction as a prediction

No actual performance or observer record accompanies the scores.

What might you notice first, and what supports that prediction?

  • Locate a specific position or timing feature, and permit an unknown response.
  • Offer an alternative interpretation compatible with the same score.

Do not convert predicted attention or emotion to an audience result.

Separate reports from events

A future comparison would need dated event descriptions and situated reports.

How would you relate an interpretation to an observable feature?

  • Record the event locator, deviations, observer viewpoint and access mode.
  • Keep performer intention, event description and observer interpretation in separate fields.

No imitation, acting, recording or participant recruitment is required here.

Try the idea elsewhere

Write one prediction, one possible contrary report and the event evidence needed to compare them. Specify an uncontrolled factor that could affect the comparison.

What a careful explanation includes
  • Identify all three planned spatial changes.
  • Distinguish target timing from measured timing.
  • Keep intention, event and interpretation separate.
  • Allow disagreement and unknown responses.
