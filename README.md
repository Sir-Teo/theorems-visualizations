# Rudin, visualized

An interactive atlas of Walter Rudin's analysis trilogy:

- **PMA** — *Principles of Mathematical Analysis*, 3rd ed. (1976)
- **RCA** — *Real and Complex Analysis*, 3rd ed. (1987)
- **FA** — *Functional Analysis*, 2nd ed. (1991)

Every numbered theorem, lemma, corollary and proposition (plus the key definitions they rest
on) has its own page with a paraphrased statement, an interactive canvas visualization, a short
"why it's true", and its place in the **dependency graph**: what it builds on, what builds on
it, and how ideas travel from one book to the next.

Site sections:

| route | what |
|---|---|
| `#/` | overview, the cross-book chapter flow, the longest chain of reasoning, load-bearing results |
| `#/book/<pma\|rca\|fa>` | chapters of a book |
| `#/book/<book>/<n>` | a chapter: its internal dependency graph and all its results |
| `#/t/<id>` | a result, e.g. `#/t/pma-4.19`, `#/t/rca-10.15`, `#/t/fa-3.4` |
| `#/map` | zoomable map of everything; hover a node to light up its ancestry and descendants |

## Running locally

No build step is needed in the browser. You need Node ≥ 18.

```bash
npm run build        # generate data/catalog.json (not committed); rerun after editing content/
npm run serve        # http://localhost:8173
npm run check        # validate content and run every visualization headless
```

`npm run check` needs `npm install` (for `playwright-core`) and a Chromium: it uses a cached
Playwright headless shell or a local Google Chrome. Useful forms:

```bash
node scripts/check.mjs pma/4 --shots      # one chapter, screenshots in shots/
node scripts/check.mjs fa-3.4 --dark      # one result, dark theme
node scripts/check.mjs --static           # schema and dependency checks only
```

## Layout

```
index.html                 single-page app shell
assets/js/app.js           router, pages, search, theme
assets/js/graph.js         lineage graph, chapter graph, chapter flow, global map
assets/js/viz/core.js      visualization runtime (stages, handles, controls, 3D, TeX labels)
assets/js/viz/math.js      numerics: integration, Fourier, linear algebra, complex numbers, …
content/<book>/chNN*.js    one module per chapter (part files allowed)
data/catalog.json          generated by scripts/build.mjs (metadata + map layout)
scripts/                   build, check, local server
AUTHORING.md               how to write an item and its visualization
```

## Deploying

`.github/workflows/pages.yml` rebuilds the catalog and publishes the site with GitHub Pages
on every push to `main`. In the repository settings, set **Pages → Source** to
**GitHub Actions**.

## Caveats

This is an unofficial study companion, not affiliated with the author or the publisher. All
statements and explanations are paraphrased; nothing here replaces the books. Theorem numbers
and dependency links were reconstructed and can be wrong — items flagged `verify: true` are the
least certain. Corrections are welcome: edit the item in `content/` and open a pull request.
